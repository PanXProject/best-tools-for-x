## About

Chronoca is a lightweight desktop time-tracking platform for remote teams, agencies, BPO companies, freelancers, and virtual assistants. It tracks work activity without the complexity of larger workforce monitoring platforms.

## Features

- Screenshot tracking
- Activity level monitoring
- URL and application tracking
- Active window tracking
- Idle time detection
- Activity percentage
- Secure data uploads
- Daily timeline reports
- Productivity reports
- Project management
- Team management
- Web dashboard
- Windows desktop app
- MacOS desktop app
