## About
ObjectRemover removes unwanted people, text, logos or objects from MP4 and MOV videos using an English text prompt. It reconstructs covered areas across frames for review and download. An account is required; new users receive three trial credits, then subscriptions or credit packs support further processing. Reconstructed detail is inferred and should be checked.

## Features
- Remove unwanted objects from MP4 and MOV videos
- Describe the target with an English text prompt
- Review the reconstructed result before downloading
