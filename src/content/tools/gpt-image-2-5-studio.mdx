## About

GPT Image 2.5 is an independent web-based AI image generator and editor for creators, designers, marketers, and small teams. Create new visuals from text prompts or upload existing images and refine them with natural-language instructions. It is designed for fast visual iteration without requiring complex design software.

## Features

- Generate new images from natural-language text prompts
- Edit existing images using simple text instructions
- Use reference images to guide visual direction and consistency
- Refine backgrounds, objects, lighting, colors, and composition
- Create multiple variations of the same visual concept
- Choose different aspect ratios for different publishing formats
- Produce higher-resolution images for detailed creative work
- Create marketing graphics, product concepts, and social media visuals
- Iterate on an existing image instead of starting over each time
- Use the tool directly in a browser without installing software
