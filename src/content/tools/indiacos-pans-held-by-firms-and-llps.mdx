## About

7,21,577 PANs whose 4th character is "F" (Firm / LLP), each with its GST registrations across states. Most registrations first. The 4th character of a PAN tells you the type of holder; this IndiaCos page groups GST registrations by that PAN so you can see every state where one entity is registered. Free to browse at https://indiacos.com/pan-type/firm-llp.

## Features

- Groups GST registrations by PAN holder type
- Shows every state where one PAN is registered
- Most registrations first
