## About
RouteMux is a reliability-first AI gateway for developers and engineering teams. Use one API key and compatible endpoints for providers including GPT, Claude, Gemini and more. Redundant upstream routes help maintain availability. Failed requests and timeouts are not charged. Prepaid pay-as-you-go usage starts at $10, with no subscription or seat fees.

## Features
- Use one API key with compatible endpoints to reach GPT, Claude, Gemini, and more.
- Route requests over redundant upstream routes to support availability.
- Failed requests and timeouts are not charged.
- Prepaid pay-as-you-go pricing starts at $10 with no subscription or seat fees.
- View API keys, quotas, usage, and request logs in one console.
