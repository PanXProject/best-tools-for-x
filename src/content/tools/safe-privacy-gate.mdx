## About
Safe Privacy Gate is a free Chrome extension that adds a lightweight check before sending text or file names to AI tools and web forms. It runs locally, sends no entered text externally, and requires no account. It never rewrites text or sends automatically, so the final decision remains with the user.

## Features
- Checks just before sending
- Runs locally in the browser
- Sends no entered text externally
- Never rewrites the user's text
- Fits individuals, freelancers, and small teams
