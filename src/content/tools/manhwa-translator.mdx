## About
Manhwa Translator gives readers an enterprise-grade comic reader. Individual users translate manga and manhwa pages in batches and customize each translation. Studio teams edit translated artwork in a complete online Photoshop-style editor. Developers connect the API to personal workflows. The platform supports all translation languages and helps teams publish localized comics.

## Features
- Translate multiple comic pages in a single batch.
- Customize translations for each project.
- Edit comic artwork in a complete online Photoshop-style editor.
- Connect the translation API to personal workflows.
- Translate comics across all supported languages.
