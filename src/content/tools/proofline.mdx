## About
Proofline reviews GitHub pull requests and reports supported findings with the evidence behind them. Built for teams on AWS and Google Cloud, it connects code changes with production context and identifies what could not be established. New organizations can start with one month of hosted code review. See the website for current pricing and availability.

## Features
- GitHub pull request reviews with cited evidence
- Findings that identify gaps and uncertainty
- Free hosted reviews for public repositories within fair-use limits
- Bring-your-own-key access with applicable provider and verification charges
