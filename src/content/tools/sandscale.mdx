## About
Sandscale runs each AI coding agent run in its own Firecracker microVM. The network is off until an allowlist opens it, secrets come from a Vault and never land in logs, and approvals plus a hash-chained audit log are on every plan. There is a free plan.

## Features
- Own Firecracker microVM with its own kernel for every agent run
- Network off until you open it with an allowlist
- Vault secrets injected in memory, never written to logs
- DLP checks on prompts and MCP tool calls
- Human approvals and a hash-chained audit log on every plan
- Pause and resume with memory and files intact
- Warm pools of pre-booted boxes from a template
- TypeScript SDK, REST API and MCP access
