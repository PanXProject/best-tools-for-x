## About
FreeAI Go is a bilingual directory for discovering free AI resources. Browse tools for chat, images, writing, voice, video, and APIs, compare free access limits, and visit official providers.

## Features
- Search and browse curated AI resources
- Compare free access and usage limits
- Find official provider websites
- Browse in English or Chinese
