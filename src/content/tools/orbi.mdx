## About

Orbi turns GitHub Issues into reviewed, merged code and tagged releases. An AI agent writes the code, a separate review verifies it, and Orbi ships. Cloud has a 14-day free trial with no credit card. The engine is open source (AGPL-3.0) and self-hosting is free.

## Features

- Label a GitHub Issue ai-ready; Orbi writes the code in an isolated working copy
- A second, independent session reviews the PR against the Issue's acceptance criteria and fixes what fails
- Reviewed code merges only after CI passes on the latest base
- A Release Issue freezes the SHA and publishes a GitHub tag and release
- Optional conversation-to-Issue drafting with acceptance criteria and clarifying questions
- Self-host the open-source engine with your own model, or use hosted Orbi Cloud
