## About
Every tool worth trying asks for an email first. TempMail.is hands that signup a disposable address: paste it in, grab the code, delete it when done. Free, no account, no install.

## Features
- A working address is already there when you open the page, with no account and nothing to install
- Read the verification code in the same tab and judge the tool on what it does
- Delete the address when the trial is over and the follow-up mail ends with it
- One fresh address per trial keeps your work inbox quiet while you test as many tools as you like
- Temporary and receive-only: it cannot send mail, and it is not for banking or anything you need to keep
