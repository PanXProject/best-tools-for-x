## About
Hailbell is in-app support chat plus push notifications for iOS, Android and web apps. Customers write from inside your app. An AI answers first from your docs and real prices, and you finish the reply from the dashboard, a Discord thread, Telegram or an AI agent over MCP. The customer gets a push when you answer. Push campaigns go to iOS, Android and web in one send, with segments, each person's local time, quiet hours and daily caps.

## Features
- An AI answers first from your docs and real prices
- Reply from the dashboard, Discord, Telegram or an AI agent over MCP
- Push campaigns to iOS, Android and web in one send
- Native Swift and Kotlin SDKs and a web widget
