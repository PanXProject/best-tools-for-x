## About

A reference page from eCourtsIndia listing the short codes used for Indian courts and cases in one place: court codes such as DLHC01 (Delhi High Court), tribunal codes such as NCLTMB0 (NCLT Mumbai), case types such as WP_C (civil writ petition) and status codes such as PENDING, with the search URL patterns, so an AI assistant, developer or legal researcher can build a correct link first time. It is the human-readable companion to ecourtsindia.com/llms.txt.

## Features

- Court, bench and tribunal codes
- Case-type and status codes
- Search URL patterns for AI agents
