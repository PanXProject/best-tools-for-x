## About
PDF Fan brings free online PDF tools together in one place. The tools run in your browser and require no account.

## Features
- Split a PDF by page range or target file size.
- Extract or delete selected pages from a PDF.
- Remove document metadata before sharing a file.
- Turn a text-based PDF schedule into an ICS file.
