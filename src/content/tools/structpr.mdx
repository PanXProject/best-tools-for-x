## About
StructPR is a GitHub App that groups the files in a pull request by business impact, so reviewers see what matters first instead of reading files alphabetically. Install it on a repo and every PR gets a structured breakdown. Free plan: 1 repo and 10 PR analyses a month. Indie is $19/month.

## Features
- Groups pull request files by business impact
- Structured breakdown on every pull request
- Free plan with 1 repo and 10 PR analyses a month
