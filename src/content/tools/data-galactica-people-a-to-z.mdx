## About

An alphabetical index of people records on Data Galactica, showing each person's education and roles where sources exist. The letter A alone holds 1,197,682 people records, with a page for every letter, free to browse. Every record carries a permanent Galactica ID (DGC- for organisations, DGP- for people), a grade and its sources. Data Galactica also offers a JSON API and MCP server.

## Features

- Lists 1,197,682 people under the letter A alone
- Shows education and roles where sources exist
- Gives every record a permanent Galactica ID
