## About
MoneyCounter is a Windows 10/11 program for counting banknotes by denomination in 78 currencies: enter how many notes of each value you have and read the total on a large display. Handy for closing a till, checking a cash box or counting savings. Free edition with a 6-digit display; Pro is USD 19 one-time.

## Features
- Banknote denominations for 78 currencies
- Large total display
- History of counts with comments
- Works offline
- Pro adds 10 digits, all notes and custom currencies
