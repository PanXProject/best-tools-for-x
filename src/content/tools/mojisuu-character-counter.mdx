## About
Mojisuu is a free Japanese character counter that runs entirely in your browser. Paste any Japanese text and instantly see character counts with and without spaces, line and paragraph counts, 400-character manuscript page estimates, plus UTF-8 and Shift_JIS byte sizes. Nothing is uploaded to a server.

## Features
- Real-time character count with and without spaces
- Line and paragraph counting as you type
- 400-Character manuscript page (genko yoshi) estimates
- UTF-8 and Shift_JIS byte length checks
- 100% Local processing with no sign-up required
