## نبذة
Social Browser متصفح مصمم لإدارة وتشغيل عدة حسابات بسهولة من مكان واحد. كل Profile يعمل بشكل منفصل ببياناته وجلساته وإعداداته الخاصة، مع أدوات مدمجة للتحكم في البروكسي والخصوصية والأتمتة، مما يساعدك على إنجاز العمل بسرعة وتنظيم أكبر.

## المميزات
- تشغيل عدة حسابات من متصفح واحد
- جلسة وCookies منفصلة لكل Profile
- الاحتفاظ بتسجيل الدخول لكل حساب
- Proxy مستقل لكل Profile
- تنظيم الحسابات باستخدام Groups وTags
- البحث والتبديل السريع بين Profiles
- تشغيل المهام على عدة Profiles
- أدوات Automation وJavaScript مدمجة
- Bulk Actions لإدارة عدد كبير من الحسابات
- أدوات مجانية لمهام Social Media
- حماية الخصوصية وحظر الإعلانات
- دعم User Scripts وإضافات المتصفح
