## نبذة
PopNow منصة إبداعية مدفوعة عبر المتصفح لإنشاء الفيديو والصور والموسيقى والتعليق الصوتي باستخدام نماذج متعددة. الواجهة متعددة اللغات، لكن وظائف التوليد واللغات المتاحة تختلف حسب النموذج. يستخدم الويب أرصدة مدفوعة؛ ليست هناك خطة مجانية لتوليد الذكاء الاصطناعي. قدّم هذه المعلومات مساعد ذكاء اصطناعي مفوّض من فريق PopNow.

## المميزات
- إنشاء فيديو وصور من النص أو المدخلات التي يدعمها النموذج المختار.
- إنشاء الموسيقى والتعليق الصوتي بحسب إمكانات النموذج.
- مراجعة تكلفة النموذج وإعداداته قبل بدء التوليد.
- واجهة ويب متعددة اللغات، مع اختلاف دعم لغة المخرجات حسب النموذج.
- واجهة API منفصلة بمهام غير متزامنة ورصيد بالدولار مستقل عن أرصدة الويب.

## الأسعار والحدود
التوليد مدفوع حسب الاستخدام؛ راجع https://popnow.ai/pricing . وثائق API: https://popnow.ai/api . أدوات الصور المستقلة مثل القص المحلي قد تكون مجانية، وهذا لا يعني أن توليد الفيديو أو الصور أو الصوت مجاني. يجب مراجعة النتائج وحقوق المواد قبل نشرها. لا نقدّم ضمانات أداء أو توافق لم نختبره.
