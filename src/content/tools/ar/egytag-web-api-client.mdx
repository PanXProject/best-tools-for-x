## نبذة

- *Egytag Web API Client** هي أداة مجانية لاختبار واجهات برمجة التطبيقات (APIs) مباشرة من المتصفح، تساعد المطورين والمختبرين على إنشاء طلبات HTTP وإرسالها وتحليل الاستجابات بطريقة عملية ومنظمة.

توفر الأداة مساحة عمل تفاعلية لتجربة واجهات REST API، مع إمكانية ضبط عناوين الطلبات، والمعلمات، والترويسات (Headers)، وبيانات الطلب (Body)، ثم استعراض النتائج وأكواد الاستجابة ومعلومات HTTP.

## المميزات

- اختبار طلبات Http: إنشاء وإرسال الطلبات باستخدام الطرق الشائعة مثل get وpost وput وpatch وdelete.
- إدارة الترويسات: إضافة وتعديل HTTP Headers بسهولة.
- معلمات الروابط: إعداد Query Parameters وتنظيمها.
- تخصيص محتوى الطلب: إعداد بيانات الطلب وتجربة واجهات API المختلفة.
- تحليل الاستجابات: عرض حالة الاستجابة، والمحتوى المسترجع، ومعلومات الطلب.
- التعامل مع Json: فحص البيانات المنظمة أثناء اختبار الواجهات.
- واجهة تفاعلية: تصميم يركز على سهولة الاستخدام وتنظيم عناصر الاختبار.
- العمل من المتصفح: الوصول إلى الأداة مباشرة دون تثبيت تطبيق مستقل.
