## About
Map Animation Studio is a browser-based editor for route animations and map videos. Creators can draw a journey, animate the route reveal, and coordinate camera moves on a visual timeline. It is designed for travel stories, educational explainers, and video presentations. Submitted by the product creator, Yaokun Lee.

## Features
- Draw and edit geographic routes on a map
- Animate route reveals with adjustable timing
- Coordinate camera movement on a visual timeline
- Export map animations for use in video projects
- Learn with a [step-by-step route animation guide](https://map-animation.com/guides/animate-a-route)
