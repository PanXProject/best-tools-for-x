## About
Kadi was built India-first — UPI as the default payment method, zero commission on what creators earn, and a link-in-bio page that doesn't force creators onto a paid plan just to get paid. It's built and run solo, prioritizing what Indian creators actually need over feature parity with US-first tools.

## Features

- Zero-commission UPI payments — creators receive payments directly via UPI with no cut taken by Kadi, unlike Linktree/Beacons which route through card processors with fees
- Link-in-bio page builder — single customizable page hosting all your links, drag-and-drop block ordering
- India-first design — built around UPI as the native payment rail instead of bolting on international gateways
- Free tier with no paywall on core features — competitors gate payment collection behind paid plans
- Web-based (works in any browser, mobile and desktop — no download required)
