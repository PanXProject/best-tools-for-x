## About
ClaudeMods is a free directory of tested Claude Code mods: status lines, safety guards, notifications and hooks. Each mod has a demo video, permission labels and a one-command install. Code: https://github.com/rotbit/claudemods-marketplace . Unofficial, not affiliated with Anthropic.

## Features
- Tested Claude Code mods in one place
- Demo video for every mod
- Permission labels show what each mod can access
- One-command install
- Links to source code for review
