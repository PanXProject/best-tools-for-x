## About

Yap Audio to Text turns an MP3, M4A, WAV or video file into editable text and SRT or VTT subtitles. OpenAI's Whisper model runs in your browser, so the file is never uploaded.

## Features

- Subtitles in SRT or VTT
- Works offline once the model is cached in the browser
- Free, no sign-up, up to 60 minutes per file
- English or any of 99 languages, detected automatically
