## About
LinkBunny helps site owners exchange contextual nofollow backlinks with other participating sites. Your coding agent proposes a placement for you to approve. The first exchange is free for one site, with no card required.

## Features
- Connect Claude Code or Codex to LinkBunny
- Manual review of each site before matching
- Your agent proposes where to add a contextual nofollow link
- You approve or decline every placement before it goes live
- The agent checks the live page and reports the placement
- First exchange free for one site, with no card required
- Paid plans cover up to 10 sites with no per-link fees
