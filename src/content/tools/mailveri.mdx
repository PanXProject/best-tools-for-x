## About
MailVeri verifies email addresses in real time and cleans bulk lists, detecting invalid, disposable, catch-all and role-based addresses so you protect sender reputation and cut bounces. Includes a free tier, REST API and an MCP server for AI agents.

## Features
- Real-time email verification API
- Bulk list cleaning and verification
- Detection of disposable, catch-all and role-based addresses
- Free tier with REST API access
- MCP server for AI agents
