## About
[VoiceFleet](https://voicefleet.ai/) is an AI inbound voice receptionist for small businesses. It uses configured instructions and FAQs to answer routine calls, capture caller messages and details, book appointments through compatible calendars, forward an existing number, route configured escalations, and provide call summaries.

## Features
- Answer inbound calls using configured instructions and FAQs
- Capture caller messages and caller details
- Book appointments through compatible calendars and provide call summaries
- Forward existing business numbers with configured escalation rules
