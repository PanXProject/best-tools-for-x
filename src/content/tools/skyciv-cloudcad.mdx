## About
SkyCiv CloudCAD is a cloud-based 2D CAD drafting tool from SkyCiv, the structural engineering software company. It runs in your web browser with nothing to install, and includes a built-in AI Assistant that makes drawing changes on request. Freemium with a 30-day free trial; paid plans from US$29/month.

## Features
- Full 2D drafting and editing commands in the browser
- Built-in AI Assistant that edits drawings on request
- Import and export of DXF, DWG, PDF, SVG and PNG
- Layers and blocks for organised drawings
- Convert 2D plans into SkyCiv Structural 3D models
