## About
Currawong's free browser-based checker checks the structure, allowed characters and check digit of an 18-character Chinese Unified Social Credit Code (USCI). It helps buyers spot input errors before researching a supplier. A passing result does not confirm company existence, current status or supplier reliability. I operate Currawong, which also offers separate, optional paid company-record reports.

## Features
- Check the 18-character structure and permitted character set
- Recalculate the check digit using the GB 32100-2015 rule
- Explain the registration authority, entity category and province prefix
- Keep the entered code in the browser during the calculation
- Read worked examples, cited sources and the limits of a passing result
