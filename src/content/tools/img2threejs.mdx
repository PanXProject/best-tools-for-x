## About
img2threejs turns a reference image into a textured 3D model packaged for the web: an optimized GLB with desktop and mobile LODs, a React Three Fiber component, a vanilla Three.js loader, editable materials, and a measured performance budget. Upload one clear photo, preview the model in your browser, and download the package.

## Features
- One image to a textured Native Mesh 3D model
- High-quality mode: 4-6 of your own views produce 3 candidates to compare
- Website component package with model.glb, Model.tsx (R3F), ModelVanilla.ts and README
- Meshopt compression, normalized scale and desktop/mobile LODs
- Measured performance budget for triangles, draw calls and file size
- Editable Procedural Draft generating readable TypeScript with named parts
- GLB and glTF downloads with failed jobs refunded automatically
