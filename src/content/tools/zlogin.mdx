## About
ZLogin is a Windows-only (v1.0.0.2) anti-detect browser for multi-account management. Each account gets its own isolated browser profile with a customizable fingerprint, an optional per-profile proxy, and team permissions. Freemium pricing: Free $0 with 2 profiles, Professional $14, Business $66.

## Features
- Isolated browser profile per account
- Customizable fingerprint (20+ options, 50+ parameters)
- Optional per-profile proxy
- Team permissions
- Multi-window Synchronizer
- No-code RPA
