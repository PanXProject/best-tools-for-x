## About
ZLogin is a Windows-only anti-detect browser for multi-account management. Each account gets its own isolated browser profile with a customizable fingerprint, an optional per-profile proxy, and team permissions. Pricing is freemium with a free plan that includes 2 profiles.

## Features
- Isolated browser profile per account
- Customizable fingerprint (20+ options, 50+ parameters)
- Optional per-profile proxy
- Team permissions
- Multi-window Synchronizer
- No-code RPA
