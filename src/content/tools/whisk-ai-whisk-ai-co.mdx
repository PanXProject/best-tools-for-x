## About
The website at whisk-ai.co provides an image creation workspace using visual references and text prompts. Users can combine subject, scene, and style references to explore new compositions and image variations.

## Features
- Combine subject, scene, and style reference images
- Generate images from text prompts
- Guide image creation with additional instructions
- Choose output aspect ratios
- Edit images through a browser-based interface
