## About
Vynaris gives teams powerful hosted uncensored models for authorized security testing, red-teaming, and research. Qwen3.8-27B, DeepSeek-V4-Flash-0731, and Qwen3.6-35B-A3B are available through an OpenAI-compatible API with published token rates and no prompt or output retention for these hosted models.

## Features
- Hosted uncensored Qwen and DeepSeek models
- Authorized security testing, red-teaming, and research
- No prompt or output retention for hosted models
- OpenAI-compatible API
- Transparent per-request cost receipts
