## About

yAssess is Youth4work's online assessment software for employers running bulk and campus hiring: online skill and aptitude tests for candidates, with results employers can use to shortlist. Part of Youth4work, an Indian talent assessment and careers platform founded in 2012 in Jaipur.

## Features

- Online skill and aptitude tests for candidates
- Built for bulk and campus hiring
- Results employers can use to shortlist
