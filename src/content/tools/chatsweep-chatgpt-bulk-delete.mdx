## About
ChatSweep: ChatGPT Bulk Delete is a Chrome extension for organizing chats loaded in your ChatGPT sidebar. Select chats, review the batch, then delete or archive with confirmation. It works locally without uploading chat titles or message content to operate. ChatSweep is independent and is not affiliated with or endorsed by OpenAI or ChatGPT.

## Features
- Select multiple loaded chats individually or search by title.
- Review batches before deleting or archiving chats.
- Protect the current chat and pause when sidebar state cannot be verified.
- Use an interface available in 25 languages.
