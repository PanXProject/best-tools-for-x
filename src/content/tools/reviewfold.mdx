## About
ReviewFold helps app developers research competitors using public App Store and Google Play reviews. It groups recurring problems, feature requests and what users value, with supporting review quotes. Start with a free preview instead of manually reading hundreds of reviews.

## Features
- Analyze public App Store and Google Play reviews
- Find recurring user problems and feature requests
- Check supporting original review quotes
- Track feedback changes for one app
