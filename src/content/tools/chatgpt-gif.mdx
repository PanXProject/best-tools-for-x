## About
ChatGPT GIF turns a text prompt or a single photo plus a motion description into a looping animated GIF using GPT Image 2.6. No sign-up is needed and the first GIF is free with no watermark. It is an independent tool, not affiliated with OpenAI.

## Features
- Generate a GIF from a text prompt or from one uploaded photo
- Nine frames at 200ms each for a smooth ~1.8 second loop
- Square 1:1, widescreen 16:9 and portrait 9:16 formats
- Results in about 20-30 seconds with no watermark
- One free GIF per visitor with no sign-up or email
- Failed generations do not use up the free credit
