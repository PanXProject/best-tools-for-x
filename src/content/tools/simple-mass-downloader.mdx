## About
Free Chrome extension for desktop Chrome that batch-downloads images, PDFs, documents, and audio/video links.
## Features
- Scan a page, open tabs, or a URL list
- Filter by type, extension, URL, or link text
- Preview images before downloading
- Save as separate files, one ZIP, or to a chosen folder
- Up to three automatic retries and clear failure reasons
