## About
SheetTutor is a free Excel learning resource with interactive browser worksheets. Learners practise spreadsheet formulas through guided tasks, calculate results and check their answers. It includes function references, original worked examples and downloadable practice workbooks. Learning content is in English, and no account is required to practise. Existing free lessons and exercises remain permanently free.

## Features
- Practise formulas in interactive browser worksheets
- Work through guided spreadsheet tasks
- Check answers while learning
- Read function references and original worked examples
- Download practice workbooks
