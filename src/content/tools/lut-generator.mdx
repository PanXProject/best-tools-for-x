## About
LUT Generator is a browser-based workflow for using a visual reference as the starting point for a reusable color look. It works with photos and normalized SDR video frames, with color refinements and optional AI suggestions.

## Features
- Match a source image or SDR frame to a reference direction.
- Fine-tune the appearance and keep a PNG preview for comparison.
- Export a custom .cube LUT for compatible editing workflows.
- Choose sRGB for photos or Rec.709 Gamma 2.4 for normalized SDR footage, matching the editor settings to the export.

## Use cases
Creators can explore a consistent palette for a photo series, compare reference-based grades for a video sequence, or build a small library of tested starting looks. A reusable LUT is a starting point, not a guarantee that unrelated shots will match.

## How to use
Choose a source and reference, check exposure and color-space assumptions, refine the look, keep a neutral baseline, and test the result on varied scenes and skin tones before production use.

## Tips and pricing
A LUT does not recover clipped detail or replace color management. The current website offers free matching, fine-tuning and PNG previews; custom .cube export uses a credit. Check the current tier limits before exporting.
