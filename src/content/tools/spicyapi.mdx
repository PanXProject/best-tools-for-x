## About
SpicyAPI provides image, video, audio and chat APIs for developers. Hosted inference is paid from a prepaid USD balance and billed by usage, without a recurring subscription. Free MIT-licensed MCP and skill clients connect compatible assistants to the paid API using the developer’s own key.

## Features
- Integrate image, video, audio and chat generation into applications
- Follow public model-specific API documentation and job workflows
- Use MIT-licensed MCP and skill clients with your own API key
