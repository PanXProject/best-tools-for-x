## About
Live Face Swap gives creators a browser workspace for trying a character on camera, exploring a visual restyle, or sketching an outfit concept. Local camera preview is free; AI generation requires login and credits and sends frames to the selected model service.

## Features
- Live webcam face swap for character rehearsals
- Restyle and virtual try-on modes for creative concepts
- Browser recording on compatible devices
- Separate camera preview and credit-based generation controls
