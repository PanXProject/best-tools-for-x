## About
AIBroll is an [ai broll generator](https://aibroll.org) that reads your script and animates it: kinetic type for key lines, animated charts for every number, icon motion for ideas. Paste a voiceover script and each line gets a matching motion design clip. It is in development; join the free waitlist for early access.

## Features
- Script-to-B-roll: every line of your script gets a matching clip
- Kinetic type for key phrases
- Animated charts for every number
- Icon motion for ideas
- Export in 16:9, 9:16 and 1:1 for Premiere Pro, Final Cut Pro, DaVinci Resolve and CapCut
