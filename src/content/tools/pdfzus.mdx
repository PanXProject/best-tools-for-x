## About
pdfzus is a browser-based PDF utility for merging, reordering, and compressing PDF files. The core workflow runs locally on the user's device and requires no account.

## Features
- Merge multiple PDF files in the browser
- Reorder documents with drag and drop
- Compress PDF files locally on the device
- Use the core workflow without registration
- Export without a watermark
