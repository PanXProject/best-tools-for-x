## About
SameMuse helps shoppers preview clothing on their own photo. Add a personal photo and a garment image or shopping screenshot to compare styling before checkout. The first Standard preview is free; use the shop’s measurements for sizing.

## Features
- Preview garments using a personal photo
- Use a garment photo or shopping screenshot
- Compare styling before deciding what to buy
