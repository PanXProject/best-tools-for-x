## About
Video2URL is a sharing tool designed to host uploaded videos, images, and PDF files under trackable URLs. It is not an AI generator, providing default unlisted links and optional MCP interface support.

## Features
- Generates shareable web links for video, image, and PDF uploads
- Default unlisted visibility and link engagement tracking
- Optional MCP interface integration for external tooling workflows
