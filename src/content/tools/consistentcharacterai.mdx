## About
ConsistentCharacterAI turns one reference portrait into a reusable character identity for new scenes. It helps creators keep faces and visual details steady while exploring poses, expressions, and story moments across a project.

## Features
- Single-photo character consistency
- Multi-pose and expression generation
- Storybook and dual-character scene creation
- High-resolution image output
