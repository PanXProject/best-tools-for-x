## About
Eglantine is a free, open-source Nintendo Switch 2 emulator for Windows, Linux and macOS. The website provides project information, release downloads, compatibility notes and setup guides, with links to the public source code and community. The project is under active development and released under GPLv3 or later.

## Features
- Free and open-source software under GPLv3 or later
- Designed for Windows, Linux and macOS desktops
- Nintendo Switch 2 emulation under active development
- Public source code and community testing resources
