## About
IcyZip is a free web app for pairing two browsers by QR code or link. It exchanges live text or one selected file without an account or installed app. Current browser clients encrypt text and file bytes before relay. Both browsers must stay online and open, and service-visible connection and file-offer metadata remain. It is not cloud storage or background clipboard sync.

## Features
- QR-code or link pairing between two browsers
- Live text exchange for short cross-device copy and paste
- One selected file transferred to the paired browser
- Browser-side encryption before ciphertext relay
- No account or app installation required
- Clear warnings when clipboard permissions block copy or paste
