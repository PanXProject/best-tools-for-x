## About
The website at lumadreammachine.app provides a browser-based workspace for generating video clips from text prompts and still images. Users can select available models and adjust video settings for creative projects.

## Features
- Generate video clips from text descriptions
- Animate uploaded images into videos
- Choose from available video generation models
- Adjust aspect ratio, resolution, and duration
