## About

Ask India Property Register a question in plain words, for example the government (circle) rate for a village, and get an answer from the register, which brings land records from hundreds of government sources together with the source and date of each fact. Part of India Property Register.

## Features

- Ask in plain words
- Answers from the land register
- Source and date for each fact
