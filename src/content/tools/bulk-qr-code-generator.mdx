## About
Bulk QR Code Generator turns a list into many QR codes in one go. Enter one URL or line of text per row, or upload a CSV or Excel (XLSX) file. Generate the batch and download every code in a single ZIP file. Choose foreground and background colours, an image size from 200 to 600 pixels, PNG or SVG output and a filename prefix. The free plan makes up to 50 QR codes per batch; the Professional plan allows up to 1,000 per batch.

## Features
- Batch QR codes from a list, CSV or XLSX file
- PNG or SVG, whole batch as one ZIP
- Colours, size (200–600 px) and filename prefix
- Logo / background image (Pro)
- Static codes: no expiry, no scan limit, commercial use allowed
- Free: 50 per batch; Pro: 1,000 per batch
- Chrome and Edge extensions
