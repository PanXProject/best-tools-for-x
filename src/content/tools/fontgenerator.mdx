## About
FontGenerator is an AI font maker that produces real, installable font files instead of pictures of letters. Describe a style, upload a reference image or a handwriting sample, and the tool returns a complete typeface you can test in the browser, refine glyph by glyph in the Studio, and download for design work, branding or a product interface.

## Features
- Real installable font files in TTF, OTF, WOFF and WOFF2
- Browser Studio for refining individual glyphs
- Latin language coverage and extra weights
- Original font library plus a font finder and language checker
- Generate a typeface from a written style description
- Turn a reference image or handwriting sample into a font
