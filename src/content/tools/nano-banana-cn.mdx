## About
Nano Banana CN is a Chinese-friendly AI image and video studio. Use Nano Banana Pro, Nano Banana 2 and 2.1, GPT Image 2, GPT Image 2.5, Seedance 2.5, Seedance 2.0 and more for text-to-image, image-to-image, text-to-video, image-to-video and video-to-video. One-time credits never expire, and an API is available for image models. Nano Banana CN is an independent site and is not affiliated with Google.

## Features
- Text-to-image and image-to-image with Nano Banana Pro, Nano Banana 2 and GPT Image 2.5
- Text-to-video and image-to-video with Seedance 2.5 and Seedance 2.0
- One-time credits that never expire
- API available for image models
