## About
SVG Animation is a browser workspace for vector icons, logos and web graphics. I am associated with this project; this listing was prepared with AI assistance. Explore the [animated svg](https://svganimation.app/) workflow to retain editable source while refining motion and preparing an export.

## Features
- Bring existing SVG artwork through a file upload or self-contained source.
- Choose motion presets and adjust duration and looping.
- Play, pause or scrub a preview before choosing a delivery.
- Keep vector source available for focused color or shape revisions.
- Describe a scene for AI-assisted creation or request a targeted revision.
- Export SVG for supported vector placements, GIF for images or MP4 for video.
- Save a local or portable project to continue a source-based review.
- Use free local editing and previews, with optional paid AI capacity.
