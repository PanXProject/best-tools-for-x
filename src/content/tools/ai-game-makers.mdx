## About
Got a Roblox game idea but no coding skills? AI Game Makers is a free Roblox AI game maker that turns one sentence into a complete game: a 3D map, Luau scripts and UI, built in one go. Watch the map grow zone by zone in your browser, then download a single .rbxlx file and press Play in free Roblox Studio. About 35 minutes on average, and your first full game is free with no card. Not affiliated with Roblox Corporation.

## Features
- One sentence in, a complete Roblox game out with zero coding
- The AI builds the 3D map, Luau scripts and UI together
- Watch the 3D map grow zone by zone right in your browser
- Download one .rbxlx file and open it in free Roblox Studio
- Make Roblox games with AI in English or Chinese
- Example maps packed with 6,097 to 16,613 parts
- Edit by chatting with the AI, with every version saved
- No plugin, no API key, nothing to install
