## About

The India Property Register API (indiapropertyregister.com/api) is an API and MCP server for Indian land and property records, for developers and AI assistants.

## Features

- Plots with published holders and owner pages
- City property tax records, circle rates and bank auctions
- MCP server for Claude, ChatGPT and other MCP clients
