## About

Skybox Generator is a browser-based tool for creating 360-degree environments from written prompts and optional reference photos. It provides a spherical preview and export options for panorama workflows. I am affiliated with this project; this description was prepared with AI assistance.

## Features

- Describe an environment with a scene prompt
- Add up to three optional reference photos
- Choose a visual style and output resolution
- Rotate the preview to inspect the surrounding scene
- Adjust the opening view, exposure and seam blending
- Export an edited PNG panorama or six cubemap faces
- Save completed projects and revisit their settings

## Practical notes

The [skybox generator](https://skyboxgenerator.org/) is a creative starting point, not a guarantee of a seamless or physically accurate scene. Check the horizon, poles, join and output rights before use. New accounts receive temporary welcome credits; related local panorama utilities can be used without credits. Paid plans and packs are optional.
