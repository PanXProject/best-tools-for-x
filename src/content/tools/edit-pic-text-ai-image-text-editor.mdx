## About
Edit Pic Text (editpictext.com) is an AI image text editor for updating words already embedded in photos, screenshots, and exported graphics. Upload an image you own or are authorized to edit, select detected text, enter replacement wording, and review the result. The AI uses the original lettering and nearby visual context as guidance, so creators can make a focused correction without rebuilding the entire design. Check the revised text and surrounding details before using the image.

## Features
- Detect and select existing text regions in an image
- Replace or remove selected words
- Make different text edits in multiple regions of one image
- Use typography and surrounding context as editing guidance
- Preview revised images before downloading
