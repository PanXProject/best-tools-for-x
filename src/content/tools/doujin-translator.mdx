## About
Doujin Translator gives manga and doujinshi readers a built-in reader and translates pages into any language. Individuals translate batches and customize the results. Studio teams edit text and page layouts in a full online Photoshop-style editor. Ficory LLC gives enterprise teams an API that connects translation to their workflows.

## Features
- Read translated manga pages in the built-in reader
- Translate batches of pages into any language
- Customize translations for individual projects
- Edit text, fonts, and layouts in the online studio editor
- Connect enterprise workflows through the translation API
