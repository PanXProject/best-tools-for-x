## About
VibeListing helps Shopify merchants create product images and SEO-ready titles and descriptions, then review changes before publishing.

## Features
- Generate lifestyle and virtual try-on images.
- Draft and diagnose listing copy and search metadata.
- Preview and publish updates in Shopify.

A free plan is available.
