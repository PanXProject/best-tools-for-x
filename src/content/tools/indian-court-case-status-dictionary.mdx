## About

A free eCourtsIndia reference that explains Indian court case statuses in one place: pending, part heard, reserved, disposed, dismissed in default and others, with what usually happens next for each. Part of eCourtsIndia, which lets lawyers, litigants and researchers search Indian court cases by CNR, party, advocate or judge, with daily cause lists. Not legal advice.

## Features

- Explains each Indian court case status
- Covers pending, part heard, reserved and disposed
- Says what usually happens next
