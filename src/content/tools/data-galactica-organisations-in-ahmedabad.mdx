## About

A free Data Galactica directory of 62,758 organisations in Ahmedabad, India, each with a permanent Galactica ID; records with contact details are listed first. Every Data Galactica record carries a permanent Galactica ID (DGC- for organisations, DGP- for people), a grade and its sources. Data Galactica also offers a JSON API and MCP server.
