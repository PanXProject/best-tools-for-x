## About
[Unrust](https://unrust.dev/) offers unassisted coding diagnostics and practice for JavaScript, TypeScript, and Python. Its diagnostic runs without AI or autocomplete and covers recall, debugging, tracing, idioms, code flaws, and reviewing AI code.

## Features
- Practice recall, debugging, and code tracing without autocomplete
- Diagnose JavaScript, TypeScript, and Python skills
- Practice reviewing AI-generated code
