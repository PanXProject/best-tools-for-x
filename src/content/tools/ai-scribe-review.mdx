## About
AI Scribe Review is a free software directory and review publication covering transcription software and related speech tools. Browse product profiles, documented features and pricing sources, provider links, editorial reviews and guides. It helps readers research software and is not a transcription engine; provider-based directory profiles do not imply hands-on testing.

## Features
- Browse transcription and related speech software profiles
- Compare documented features and pricing sources
- Follow provider links for current software information
- Read editorial reviews and software selection guides
