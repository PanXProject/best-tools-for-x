## About
AI Fruit Video is a browser app for short stories starring expressive fruit characters. Start with a text prompt and optional reference images, choose video settings, generate a clip, then preview and download it. It supports playful talking-fruit scenes and fruit drama ideas. Creating an account is free; generation requires paid credits. One-time packs start at $10 for 150 credits, with optional subscriptions available.

## Features
- Turn text prompts into short fruit-character scenes
- Add optional reference images to guide a scene
- Preview generated clips and download the result
