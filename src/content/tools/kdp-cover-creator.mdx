## About

KDP Cover Creator is a browser-based workspace for designing and revising book covers. It supports editable text and artwork layers, front, spine and back layout, dimension checks and a full-wrap PDF export. This listing is project-associated and was prepared with AI assistance. ## Features

- Arrange editable title, subtitle and author text layers
- Adjust front, spine and back cover layouts
- Check dimensions and placement before export
- Export a full-wrap PDF and an editable project backup
- Explore optional AI artwork using available credits
- Compare a digital cover mockup before further review

## Practical notes

Authors should check current printer specifications, proofread the exported file and verify rights to all visual elements. Digital checks do not guarantee print acceptance. This project is not affiliated with Amazon.
