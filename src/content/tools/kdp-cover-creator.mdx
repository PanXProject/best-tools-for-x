## About

KDP Cover Creator is a browser-based workspace for designing and revising book covers. It provides editable text and artwork layers, tools for front, spine and back layout, dimension checks, and a full-wrap PDF export. This project-associated description was prepared with AI assistance.

## Features

- Edit text and artwork as separate layers
- Arrange front, spine and back cover panels
- Check cover dimensions before exporting
- Export a full-wrap PDF and editable project backup
- Explore optional AI artwork using available credits

## Practical notes

Authors should proofread their exports, verify image rights and check current printer specifications. The tool does not guarantee print approval and is not affiliated with Amazon.
