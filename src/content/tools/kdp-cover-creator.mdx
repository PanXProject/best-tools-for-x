## About

KDP Cover Creator is a browser workspace for creating and revising editable book covers. I am associated with the project; this listing was prepared with AI assistance. Use [create book cover for amazon kdp](https://kdpcovercreator.app/) to arrange text and artwork, review dimensions and prepare an export.

## Features

- Arrange front, spine and back cover panels
- Edit title, subtitle and author text as separate layers
- Replace artwork and adjust its placement
- Check layout dimensions before export
- Export a full-wrap PDF for further review
- Save an editable backup for future revisions
- Explore optional AI-generated artwork using credits

## Practical notes

Authors should proofread their exported files, check current printer specifications and verify image rights. Preview and dimension checks do not guarantee print acceptance. This project is not affiliated with Amazon, and optional AI generation is not unlimited.
