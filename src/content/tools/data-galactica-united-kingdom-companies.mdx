## About

A free Data Galactica directory of 5,858,274 organisations in United Kingdom, browsable without a login. Every record carries a permanent Galactica ID (DGC- for organisations), a grade and its sources, with records that have contact details shown first. Data Galactica also offers a JSON API and MCP server for KYB, research and AI agents.

## Features

- Lists 5,858,274 organisations in the United Kingdom
- Gives each record a permanent Galactica ID
- Shows records with contact details first
