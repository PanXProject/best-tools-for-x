## About

ExcelTool.io is a free set of browser-based spreadsheet tools. Convert XLSX to CSV, JSON or PDF, view and edit Excel files without Office, merge and split workbooks, and repair damaged files.

## Features

- Excel to CSV, JSON and PDF converters
- View and edit spreadsheets online
- Merge, split and repair workbooks
- Most tools run locally, so files stay private
