## About

IndiaRestros is a free, open guide to every restaurant, cafe, stall and dhaba in India: no paid rankings and no commissions. Each restaurant gets one page and one permanent id, built from open data and public listings with the source of every fact on record. Foodies browse free, restaurants list, claim and correct their page free, and AI agents read everything free through a public REST API (no key needed for reads).

## Features

- One page per restaurant
- No paid rankings or commissions
- Free API for AI agents
