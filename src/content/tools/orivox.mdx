## About
Orivox is an AI website builder for small businesses. It edits live websites using a constrained operation grammar and guardrails so changes stay safe and reversible. Not related to orivox.ai.

## Features
- AI-driven edits to live websites
- Constrained operation grammar for safe changes
- Guardrails with reversible changes
