## About
Dot Symbol is a free browser tool for finding and copying bullet dots, middle dots, circle dots and math dots, with searchable categories, a separator builder and Unicode, HTML, CSS and JavaScript references for every character.

## Features
- Search and copy bullet, middle, circle and math dots
- Separator builder for creating custom dot strings
- Unicode, HTML, CSS and JavaScript references for each symbol
- Keyboard guidance and side-by-side character comparisons
- Free in the browser with no sign-up
