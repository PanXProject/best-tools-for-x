## About

TypeChart helps Pokemon players check type matchups, calculate dual-type weaknesses, spot shared team weaknesses, and choose natures. The free browser tools support generation-specific type rules, shareable teams, and a dedicated Pokemon Champions roster. Core tools work without registration. TypeChart is an independent, unofficial fan tool.

## Features

- Generation-specific type charts, so old and new rules never get mixed up
- Dual-type weakness calculator that shows 4x, 2x, 0.5x and 0x multipliers at once
- Team builder that flags weaknesses several team members share
- Nature chart for picking the right stat trade-off
- Dedicated Pokemon Champions roster
- Shareable team links, no account needed for the core tools
