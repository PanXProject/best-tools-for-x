## About

A free eCourtsIndia encyclopedia of 260+ case type codes used in Indian courts and tribunals, such as WP_C, BA, SLP_C, CP_IBC and OA_DRT, explaining each code with a one-click search for cases of that type. Part of eCourtsIndia, which lets lawyers, litigants and researchers search Indian court cases by CNR, party, advocate or judge, with daily cause lists. Not legal advice.

## Features

- Explains more than 260 case type codes
- Covers courts and tribunals across India
- Gives a one-click search for each code
