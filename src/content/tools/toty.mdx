## About
Toty is a web-based AI image and video generation platform that brings multiple generation models into one interface and shows clear per-model pricing before each run.

## Features
- Generate images with multiple AI models
- Generate videos with multiple AI models
- Compare model pricing before every generation
- Use the platform directly from a web browser
