## About
Chrome and Edge extension that saves Gmail emails as PDFs in bulk, merges up to 50 into one PDF to save or print, and keeps attachments. Nothing is uploaded.

## Features
- Bulk export selected emails, a label, or a search result, each conversation saved as its own PDF
- Merge up to 50 conversations into one PDF, one email per page, to save or print as a single job
- Attachments saved alongside each PDF in a zip, with original files intact
- Adds PDF and Print buttons to Gmail's own toolbar, with no setup after installing
- Custom filename template built from date, sender and subject, plus portrait or landscape and eight paper sizes
- PDFs generated locally in your browser, so no email or attachment is uploaded to any server
