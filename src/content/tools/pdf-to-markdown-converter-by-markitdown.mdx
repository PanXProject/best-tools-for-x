## About
MarkItDown's PDF to Markdown Converter turns PDFs into editable Markdown online. Preview the result, copy it, download a .md file, or open it in the online editor. Standard conversion is free with no sign-up, up to 20MB per file and three files per batch. Scanned PDFs are supported with OCR.

## Features
- Convert PDF files to editable Markdown in the browser
- Preview headings, paragraphs and tables before downloading
- Choose cloud conversion or on-device processing
- Scanned PDF support with free local OCR and AI OCR
- Download all results together as a ZIP
- Export as an Obsidian note or split by headings
