## About
Take a Break Button is a small browser tool for marking a pause between tasks. A single button opens a short, calming experience, giving screen users a simple way to step away from a busy workflow.

## Features
- Open a short break experience with one button
- Use the tool directly in a web browser
- Return to your task when you are ready
