## About
Emoji Start With a Letter is a free web utility that organizes 1418+ emojis by the first letter of their Unicode name. Pick any letter A–Z to see every matching emoji, or search by name, then click to copy to your clipboard for messages, social posts, and docs.

Beyond the letter grid, the site includes popular emoji meaning guides, mood-based emoji combos, and a heart-emoji color decoder — so you can find the right emoji and understand how people actually use it.

## Features
- A–Z letter grid covering 1418+ emojis
- One-click copy to the clipboard
- Search by emoji name
- Emoji meanings and combo guides
- Multilingual pages for finding emojis
