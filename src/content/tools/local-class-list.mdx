## About
Local Class List is a hand-verified directory of local adult classes across 28 US cities. Dance, tennis, pickleball, pottery, flower arranging and mahjong are listed with real prices and schedules. Book direct with the studio or coach. No marketplace fees.

## Features
- Hand-verified prices and schedules from each provider site
- Dance, tennis, pickleball, pottery and similar group classes
- Coverage across 28 US cities for in-person adult classes
- Book directly with the studio or coach with no checkout fee
- Every listed price cites the provider source page
