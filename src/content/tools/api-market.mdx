## About
API.market is an API marketplace and proprietary hosted MCP gateway for developers and AI agents. Discover APIs, inspect operations and call them through one connection. An account and OAuth or an API key are required. Free tiers and paid plans vary by API.

## Features
- Remote Streamable HTTP MCP endpoint: https://api.market/api/mcp/gateway
- Search APIs and inspect available API tools
- Call API operations and check usage
- Manage API subscriptions
- Setup documentation: https://api.market/mcp
