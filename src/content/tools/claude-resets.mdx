## About
Claude Resets records every Claude Code usage-limit reset announced by @ClaudeDevs and Claude Code team members, with time since the last reset, history, stats, and Codex resets. It offers RSS feeds, an ICS calendar, a JSON API at /api/resets, a status-line script, and a read-only remote MCP server (claude mcp add --transport http claude-resets https://claude-resets.com/mcp). Free, no account. Not affiliated with Anthropic.

## Features
- RSS feeds of every reset
- ICS calendar subscription
- JSON API at /api/resets
- Read-only remote MCP server
- Status-line script for Claude Code
- Reset history and stats, including Codex resets
