## About
Fluxtail brings application logs together for centralized search and Live Tail. Hosted HTTP MCP lets compatible AI tools investigate account logs through account-scoped, revocable OAuth access.

## Features
- Search application logs from one central place
- Follow new log events with Live Tail
- Connect compatible AI tools through hosted HTTP MCP with revocable OAuth access

A 14-day trial is available without a card. Paid plans start at $19/month.
