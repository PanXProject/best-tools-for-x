## About
An independent third-party host for Jev, a decision model that returns typed labels and probabilities (choice, score, yes/no) for classify, route and moderate tasks. Five free runs, then prepaid packs from $5. Not TypeSafe official.
## Features
- Returns typed labels and probabilities for each decision
- Handles classify, route, and moderate tasks
- Supports choice, score, and yes or no outputs
- Includes five free runs before prepaid packs
