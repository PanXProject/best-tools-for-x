## About
An independent third-party host for Jev, a decision model that returns typed labels and probabilities (choice, score, yes/no) for classify, route and moderate tasks. 5 free runs; prepaid packs from $5. Not TypeSafe official.

## Features
- Returns typed labels and probabilities for classify, route, and moderate tasks
- Supports choice, score, and yes/no decision outputs
- Includes 5 free runs so you can try the hosted API
- Offers prepaid packs starting at $5 after the free runs
- Independent third-party host, not the official TypeSafe product
