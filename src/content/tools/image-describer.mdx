## About

Image Describer is a free online AI image describer that turns photos, screenshots, and illustrations into clear, editable text. Upload a JPG, PNG, or WebP image, pick from eight modes including general description, alt text, OCR, and image-to-prompt, then set length and output language. The public tool is completely free and requires no sign-up.

## Features

- Turn photos, screenshots, and illustrations into clear written descriptions
- Choose from eight tasks including general description, people and clothing, objects and details, style and composition, OCR, alt text, image to prompt, and ask a question
- Set the description length to short, standard, or detailed
- Generate output in English, Simplified Chinese, Spanish, French, German, Japanese, Korean, or Portuguese
- Extract text from images while preserving line breaks
- Copy the generated text or download it as a .txt file
- Use the tool with no sign-up, and images are not saved to an account
