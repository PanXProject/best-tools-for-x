## About
MysticRemora is a free, evidence-backed directory for finding local game stores, card shops, board game stores, game cafés, and places to play across the United States and Canada.

## Features
- Search by store name, city, ZIP code, or postal code
- Browse stores by tabletop game or category
- Discover Magic, Pokémon, Dungeons & Dragons, Warhammer, and board-game locations
- Review transparent source details for store listings
- Submit corrections through an easy public process
