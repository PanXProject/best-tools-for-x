## About

Gender Swap AI is a browser-based creative tool for gender-swapped portraits, fan art and original characters. Start with a prompt, optionally add reference images and a visual style, then generate, refine and download images. A free weekly allowance is available, with paid subscriptions and one-time credit packs for more usage.

## Features

- Prompt-based gender-swapped portraits and character art
- Optional reference images and selectable visual styles
- Generate, refine and download images in a web browser
