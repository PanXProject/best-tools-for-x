## About
Kepo is a Mac desktop app that puts custom widgets on your screen from websites, RSS feeds, and AI, so useful info stays visible while you work.

## Features
- Build custom Mac desktop widgets from any website
- Follow RSS feeds and live data without opening a browser
- Keep AI-built widgets on the desktop while you work
