## About
Y2K Photo Editor is a browser workspace for applying early-digital color, grain and texture to photos. I am associated with the project; AI assisted this listing. Use the [y2k photo editor](https://y2kphotoeditor.online/) to compare a treatment with the original before saving.

## Features
- Apply nostalgic color and texture effects to an image.
- Compare the edited result with the original photograph.
- Crop, reposition and rotate the image for its destination.
- Add custom stamps and explore additional Studio controls.
- Download a watermarked JPG with the free editor.
- Access additional export options and batch editing with paid Studio.

## Practical notes
Use only images you have permission to edit and share. The website says processing occurs on the device; download the result before leaving because there is no cloud project. Free and paid options have different limits, so check the official site for current pricing and features. Review details at the size and in the context where the image will appear.
