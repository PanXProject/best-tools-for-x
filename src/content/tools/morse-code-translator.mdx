## About
Morse Code Translator converts plain text to Morse code and decodes Morse back to text as you type, entirely in the browser. It handles letters, numbers and punctuation, plays the message as audio beeps so you can hear the rhythm, and lets you copy the result or share a link. No account, install or upload is needed.

## Features
- Instant two-way conversion between text and Morse code
- Letters, numbers and punctuation supported
- Audio playback of the Morse signal
- Copy or share the result in one click
- Runs fully in the browser with no sign-up
