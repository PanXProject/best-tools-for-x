## About

Nano Banana 3 is a browser-based AI image generator and editor. Users can create images from text prompts or upload photos as references for image editing.

It can be used for product images, profile avatars, concept art, and social media visuals. Start with a prompt, reference images, or both, describe the desired result, then generate and download the output. No desktop software installation is needed.

## Features

- Generate images from text prompts.
- Edit uploaded photos with natural-language instructions.
- Combine multiple reference images.
- Change image backgrounds.
- Explore different visual styles.
- Generate and download images in a web browser.
