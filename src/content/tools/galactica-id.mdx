## About

A Galactica ID is a permanent identifier for a person (DGP-) or an organisation (DGC-). The page explains which external ids resolve to it and what the record grades mean. Part of Data Galactica.

## Features

- Permanent ids for people (DGP-) and organisations (DGC-)
- Shows which external ids resolve to a record
- Explains record grades
