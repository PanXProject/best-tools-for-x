## About

A free Data Galactica list of the best-known companies in Japan: the best-covered organisations in its records, each with a permanent Galactica ID, a data grade and the sources behind it. Every Data Galactica record carries a permanent Galactica ID (DGC- for organisations, DGP- for people), a grade and its sources. Data Galactica also offers a JSON API and MCP server.

## Features

- Lists the best-covered organisations in one country
- Gives each a permanent Galactica ID and a grade
- Shows the sources behind every record
