## About
Unplayable is a progressive web app from Shadow Hands that helps you become the one nobody can play. It teaches you to spot, name and counter manipulation through 99 moves, each taught in a 2-minute lesson. You also get daily drills, live role-play practice, and an advisor that reads your situation. It is built for defence and awareness, not therapy.

## Features
- 99 Manipulation moves, each taught in a 2-minute lesson
- Daily drills
- Live role-play practice
- Advisor that reads your situation
