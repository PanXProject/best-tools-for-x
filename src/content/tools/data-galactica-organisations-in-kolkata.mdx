## About

A free Data Galactica directory of 89,189 organisations in Kolkata, India, each with a permanent Galactica ID; records with contact details are listed first. Every Data Galactica record carries a permanent Galactica ID (DGC- for organisations, DGP- for people), a grade and its sources. Data Galactica also offers a JSON API and MCP server.

- Lists organisations in one Indian city
- Gives each a permanent Galactica ID
- Puts records with contact details first
