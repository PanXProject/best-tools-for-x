## About
Check STL mesh errors and apply supported basic fixes for free in your browser. Advanced repair is optional. STLRepair helps makers inspect STL files, preview mesh diagnostics, repair supported issues locally, and download results without signup.

## Features
- Check open boundaries, non-manifold edges, invalid triangles, and duplicate faces
- Preview binary or ASCII STL models in an interactive 3D viewer
- Apply supported basic repairs locally and download the repaired STL
- Choose optional advanced repair for eligible complex models
