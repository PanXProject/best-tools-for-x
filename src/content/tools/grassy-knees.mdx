## About
Grassy Knees is a family activity directory for infants through teens across America’s 42 largest metro areas. Every listing links to the organizer’s own page and shows when we last verified it—so parents can plan this weekend with less guesswork. Free to browse; also on iOS and Android.

## Features
- Browse real-life kids activities near you across 42 metro areas
- Every listing links straight to the organizer’s own page
- See when each activity listing was last verified
