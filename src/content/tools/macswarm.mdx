## About
Macswarm runs macOS virtual machines (Pods) on Apple silicon and exposes them to coding agents. Claude Code attaches through Anthropic's self-hosted environments; Codex through the OpenAI Agents API webhook. A Pod ships with the Latest Xcode, iOS runtimes, pre-booted Simulators and a two-slot build queue. Free plan: 3 Pod-hours, no card.
## Features
- Latest Xcode and pre-booted iOS Simulators in every Pod
- Billing per Pod-hour, metered per second, idle Pods stop
- Each Pod is cloned fresh and destroyed after the session
- EU (Netherlands) and US regions
