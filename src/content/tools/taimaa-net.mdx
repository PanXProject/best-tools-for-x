## About
Taimaa is a free online timer for Japanese users that opens instantly in the browser with no account and no download. Set a countdown for cooking, study, work intervals or a short break, then let the page keep time and alert you when it finishes. The interface is in Japanese and works on phones, tablets and desktops.

## Features
- No sign-up and no download, the timer starts right away
- Japanese interface built for everyday use
- Works on phone, tablet and desktop browsers
- Quick presets for common intervals
- Clear sound alert when the countdown ends
- Readable display for kitchen, desk or classroom use
