## About
Formatide is a free browser toolkit for converting images and data, and making 2/3/4-image collages without uploading files. No signup or installation is required. Preview layouts, reorder images and adjust spacing in supported image converters. File processing runs on your device; optional analytics requires consent.

## Features
- Combine 2, 3 or 4 images with layout previews, ordering, spacing and margins
- Export SVG images or collages as PNG, JPG or WebP
- Convert supported PNG, HEIC, WebP, AVIF and JFIF images to JPG
- Export SVG artwork as multi-size ICO files
- Arrange JPG or HEIC photos into PDF pages
- Convert tables between CSV and JSON
- Download batches with ZIP support where available
- Process files locally with clear format and size limits
