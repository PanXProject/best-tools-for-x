## About

Jolene.pro is an AI spreadsheet analysis tool for recurring work across complete Excel and CSV workbooks. It compares records across sheets, investigates discrepancies, creates charts, and links findings to supporting cells. Save an analysis and rerun it on the next reporting file. Jolene.pro handles supported changes such as renamed sheets, reordered columns, and shifted tables while flagging changes that require review.

## Features

- Save and rerun analyses on new weekly or monthly workbooks
- Analyze multiple sheets, separate tables, and irregular layouts
- Compare records, totals, dates, and identifiers across sheets
- Trace findings and calculations to supporting cells
- Create charts, KPI cards, and dashboards
- Adapt to supported sheet, column, and table changes
- Flag workbook changes that require review
- Analyze files without modifying the original workbook
