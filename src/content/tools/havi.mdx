## About
Havi is an AI design partner that turns a one-line prompt into a fully designed presentation deck, complete with layouts, images, and structure already in place.

## Features
- Generate full slide decks from a single text prompt
- Turn an existing outline into a designed deck automatically
- Edit any slide with AI assistance
- Swap themes across the whole deck in one click
- Add charts and other visual elements
- Export to PDF or PPTX ready to present
