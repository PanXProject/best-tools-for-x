## About
ZKStamp Proof-100 stamps a file's SHA-256 fingerprint on the BitcoinZ blockchain, shielded with zk-SNARKs. AI agents use it via MCP.

## Features
- Shielded timestamps: the fingerprint is hidden inside a zk-SNARK shielded transaction.
- Privacy by design: only the SHA-256 fingerprint is sent, never the file.
- One new address and one viewing key per proof: reveal one proof without exposing the others.
- Independent verification with ZCheck (open source), on any BitcoinZ node.
- MCP server for AI agents: timestamp_fingerprint, timestamp_text, check_balance.
- REST API for scripts and servers.
- No card, no email, no account name: pay in BTCZ.
- Free trial: 3 free proofs for new accounts.
- Open source, MIT license.
