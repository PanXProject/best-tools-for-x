## About

An alphabetical index of company records on Data Galactica. The letter A alone holds 1,144,239 company records, and every letter from A to Z has its own page, so researchers and KYB teams can browse organisations by name without a login. Every record carries a permanent Galactica ID (DGC- for organisations, DGP- for people), a grade and its sources. Data Galactica also offers a JSON API and MCP server.

## Features

- Lists 1,144,239 companies under the letter A alone
- Gives every record a permanent Galactica ID
- Shows a grade and the sources for each record
