## About

GPT Image Generator helps brand designers explore brand moodboards and launch directions with optional image references. Use text prompts and optional image references to compare visual directions, with anime, pixel and sketch styles and multiple aspect ratios. Review drafts and refine prompts before publication. Sign-in is required for the advertised free trial; continued use follows credit and plan limits.

## Features

- Create visual drafts from written prompts
- Guide image concepts with optional reference images
- Explore anime, pixel and sketch style choices
- Choose an aspect ratio for the intended use
