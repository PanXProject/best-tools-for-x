## About
AI Anime Generator is a browser-based creative tool for generating anime characters, portraits, and scenes from text prompts. Optional reference images can guide identity and costume details, while multiple styles support different visual directions.

## Features
- Generate anime characters and scenes from text prompts
- Guide visual identity with optional reference images
- Explore cinematic cel, retro, chibi, pastel, and manga styles
- Compare multiple concepts in a browser-based workflow
- Create portraits and scene ideas without installing software
