## About
TryH3 is a browser-based video generator for creating short AI videos with MiniMax H3. It provides a direct web workspace for describing scenes and producing visual drafts without installing desktop software or assembling a local workflow.

## Features
- Browser-based MiniMax H3 video creation
- Direct workflow for visual drafts
- No local installation required
