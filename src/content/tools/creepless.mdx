## About
Creepless is scope-creep software for agencies and freelancers. Each client gets a no-login request link. An AI referee checks every ask against the agreed scope: included work proceeds, extras become a quote the client approves first. Free for 2 clients and 20 AI checks a month; no card required.

## Features
- Private request link for each client, with no client login
- Every request checked against the agreed scope, with the rule cited
- Ready-made replies for out-of-scope requests
- Quotes the client approves on their link before work starts
