## About
ImgAPI helps developers add image generation and editing to applications through one API key. Use GPT Image, Nano Banana and Seedream with prepaid USD credits. Costs vary by model and image settings. Compare outputs in the web playground before integrating.

## Features
- Generate images from text prompts
- Edit images using reference images
- Poll asynchronous tasks to retrieve completed results
- Integrate with cURL, Node.js and Python examples at https://imgapi.ai/api-docs
