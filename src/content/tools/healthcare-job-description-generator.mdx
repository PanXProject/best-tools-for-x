## About
Healthcare Job Description Generator is a free AI tool for healthcare employers: clinics, practices, home care agencies, nursing homes and hospitals. Name the role, the setting, the schedule and the pay you will post, add what the person needs and what makes the job good, and it writes a clear job description in the order job seekers read (title, schedule, pay, duties, requirements, benefits, how to apply), using only your facts.

## Features
- Free to use, no sign-up
- Nothing you enter is stored
- Built on Claude by Anthropic
