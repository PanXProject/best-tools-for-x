## About
subtitle.im is a YouTube Chrome extension. Upcoming 1.6 adds reading, search, time jumps, copy and downloads from available captions: free TXT; Pro SRT, VTT, Markdown and browser print/save PDF. Follow YouTube or turn captions on/off automatically. Local OCR helps handle duplicates; restore captions anytime. Duplicate handling has a cumulative 10-video trial without signup. Pro adds continued handling, video/channel rules and remembered closures. No transcription or translation.

## Features
- Caption modes: Follow YouTube, Auto-open and Auto-close
- Local duplicate-caption handling and restoration
- Upcoming 1.6: search, seek and copy available captions
- Upcoming 1.6: free TXT; Pro SRT, VTT, Markdown and browser print/save PDF
