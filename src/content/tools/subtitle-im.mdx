## About
subtitle.im is an all-in-one YouTube Chrome extension. The upcoming 1.6 release adds transcript reading, keyword search, timestamp jumps, copying and downloads from available captions. Control captions with Follow YouTube, Auto-open or Auto-close, handle duplicates locally and restore captions anytime. Caption processing includes a 10-video trial without signup. Optional Pro adds continued handling, video/channel rules and memory of confirmed closures. It does not alter burned-in text.

## Features
- Caption modes: Follow YouTube, Auto-open and Auto-close
- Local duplicate-caption handling and restoration
- Upcoming 1.6: search, seek and copy available captions
- Upcoming 1.6: free TXT; Pro SRT, VTT, Markdown and browser print/save PDF
