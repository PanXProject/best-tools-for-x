## About

SendHQ gives product teams and AI agents one coherent email workflow: verify domains, send transactional messages, receive email, inspect delivery outcomes, and manage workspace-scoped API keys. Its public REST API is Resend-compatible and designed for serious product communication with clear observability and sender-safety controls.

## Features

- Transactional email API
- Inbound email
- Verified sending domains
- Delivery event visibility
- Workspace-scoped API keys
- Agent-facing API documentation and MCP server
