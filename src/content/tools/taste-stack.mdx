## About
Taste Stack offers installable creative direction skills for Claude Code, Codex and Cursor. Use a design skill to guide typography, spacing and layout on a website, or a motion skill to guide timing and visual style in a launch video. Four starter skills are free with an account. Additional skills are available individually or by subscription.

## Features
- Install a reusable visual direction in a compatible coding agent.
- Preview frontend design and motion styles before choosing a skill.
- Try four free starter skills with your own agent and model access.
