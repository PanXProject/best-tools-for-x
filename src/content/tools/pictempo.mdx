## About

PicTempo is a browser-based photo-to-video maker for turning still photos into a shareable MP4 slideshow.

## Features

- Arrange 2-24 photos per project
- Set per-photo duration
- Choose cuts or fades
- Optional background music
- Preview and export MP4 without signing in
