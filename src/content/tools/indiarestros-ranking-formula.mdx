## About

IndiaRestros publishes how it ranks restaurants: rank = 100 x (0.45 x confidence + 0.30 x completeness + 0.15 x independent sources (up to 3) / 3 + 0.10 x has a phone number). Restaurants cannot pay to move up. Confidence measures how reliable and consistent the sources are; completeness counts basics like phone, timings, menu and photos. IndiaRestros lists 15,71,714 places to eat in India.

## Features

- Published ranking formula
- No paid placement
- Confidence, completeness, sources and phone
