## About
LuauCheck is a free web tool for Roblox creators. Describe a mechanic in one sentence and it writes a Luau script and tells you exactly where the script belongs in Roblox Studio: which object, which Script / LocalScript / ModuleScript, and which Explorer path. Examples and guides are free and need no account. Not affiliated with Roblox Corporation.

## Features
- Turn one sentence into a ready-to-use Roblox Luau script
- Shows exactly where the script goes in Studio (object, script type, Explorer path)
- Syntax, placement and sandbox checks on every result
- Free script examples and beginner placement tutorials
