## About
EzImageAI is a browser-based AI image editor built around prompts instead of fixed templates. Upload a photo, describe the change you want, and review the result in one workspace, with 12 models across GPT Image, Nano Banana and Seedream families.

## Features
- Prompt-based photo editing for backgrounds, colors and style
- Text-to-image with an optional reference image
- Twelve models from three families
- Prompt recipes and per-model prompt ideas
- Credit cost shown before each generation
- Private assets and private edit history
