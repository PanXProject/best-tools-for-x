## About
DnD Map Maker is a browser-based tool for planning fictional tabletop encounter maps. Sketch rooms and routes, generate a top-down scene, revise a selected area, and export the result for play. This listing is project-associated and AI-assisted; game rules, accessibility, permissions, and final use remain human decisions.

## Features
- Plan rooms, routes, entrances, and encounter objectives before rendering
- Generate top-down fantasy map candidates from a structured scene brief
- Revise selected areas without discarding every accepted map decision
- Review scale, token movement, sight lines, cover, and elevation
- Separate player-safe exports from game-master notes and hidden information
- Export map images for tabletop preparation and virtual tabletop testing
- Use free map-making access with optional paid features kept separate
- Keep human review in control of rules, rights, accessibility, and publication

## Practical notes
Start with a short encounter brief and treat every generated image as a candidate rather than an automatic answer. Compare routes and scale against the intended encounter, test representative token movement, and inspect the exported file at actual play size.

The [dnd map maker](https://dndmapmaker.com/) supports an iterative planning and revision workflow. AI can accelerate visual exploration, but it does not certify balance, safety, accessibility, ownership, or suitability for a particular game group.
