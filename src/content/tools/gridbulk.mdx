## About

GridBulk is a batch AI image generation tool built around grid splitting: one prompt produces a grid image (1x1 to 4x4) that is automatically split pixel-perfect into up to 16 individual images.

## Features

- One prompt generates a grid (1x1 to 4x4) split pixel-perfect into up to 16 images
- Three modes: single (batch), gacha (style exploration), compose (mockups and ad variants)
- REST API with sync/async batch endpoints, MCP server, published OpenAPI spec
- One credit per generation regardless of grid size
- English and Chinese UI

## Pricing

Free tier with 20 trial credits (no card required). Credit packs from $5 never expire. Subscriptions $19/$49/$99 per month.
