## About
CurlShot turns any web page into an image, PDF or video with one HTTP request. Send a URL, your own HTML or Markdown and get back a PNG, JPEG, WebP, PDF, MP4, WebM or GIF. Pages render in a real browser. Built-in MCP server for AI agents. No SDK needed. The free plan has 100 screenshots a month, no card.

## Features
- Full-page screenshots with lazy images loaded
- Phone, tablet and desktop device presets
- Cookie banners, ads and chat bubbles removed before capture
- One element by CSS selector, dark mode, retina
- PDF and scrolling video (MP4, WebM, GIF) output
- Async jobs with signed webhooks, bulk runs of up to 100 URLs
- MCP server, OpenAPI 3.1 and llms.txt for AI agents
