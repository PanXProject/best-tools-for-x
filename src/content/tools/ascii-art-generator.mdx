## About

ASCII Art Generator is a browser toolkit for image and text character art, manual cell editing, and copying or exporting a result. Use the [ascii maker](https://asciiartgenerator.online/) for visual experiments, then check the destination font and spacing before sharing. Core browser tools are free; optional AI rendering uses credits.

## Features

- Turn a clear source image into a character grid for visual experimentation.
- Create character art from text for project headings and compact illustrations.
- Refine individual cells manually instead of replacing an entire composition.
- Copy or export the result using the available browser interface controls.
- Inspect output width, whitespace, and background contrast for the intended destination.
- Use free core browser tools separately from optional credit-based AI rendering.
