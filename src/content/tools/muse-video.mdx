## About
Muse Video is a prompt-led workspace for developing video concepts. You describe the subject, its motion, the camera treatment, visual details and the audio direction in one place, then iterate on the result. The underlying model is preview-stage, so we describe capabilities as directional rather than fixed specifications.

## Features
- Single written prompt covers subject, motion and camera direction together
- Visual detail and native-audio cues are set alongside the video prompt
- Concept-first iteration so you can compare directions quickly
- Web-based workspace with no install step
