## About
TextRemover.video helps creators remove unwanted text, captions and hardcoded subtitles from videos using AI background reconstruction. Upload an MP4 or MOV file and choose a removal mode. Eligible signed-in accounts receive 30 free processing seconds each month, with no credit card required.

## Features
- Select area, Subtitles or All text removal modes
- Supports landscape and portrait videos
- Browser-based workflow with no editing software to install
- 30 Free processing seconds per month for eligible accounts
