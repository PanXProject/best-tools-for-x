## About
Bulk Barcode Generator is a web tool for making many barcodes at once. Enter one value per line, or upload a CSV or Excel (XLSX) file; example files are provided so you can match the layout. Then generate the whole batch and download it as a single ZIP file.

## Features
- Batch generation from a list, CSV or XLSX file
- 11 Symbologies: CODE 128, EAN-13/EAN-8/UPC/EAN-5/EAN-2, CODE 39, ITF-14, MSI, Pharmacode, Codabar
- PNG or SVG output, whole batch as one ZIP
- Colours, size, margin, font and text position settings
- Free: 20 per batch; Pro: 1,000 per batch
