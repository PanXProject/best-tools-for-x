## About
Whisk AI is an online image generation and editing studio. Create images using subject, scene, and style references or text prompts, then refine results with conversational editing. It helps creators make concept art, product visuals, and social media graphics.

## Features
- Blend subject, scene, and style reference images
- Generate images from text prompts
- Refine images with conversational editing
- Choose output aspect ratios
- Create multiple image variations
