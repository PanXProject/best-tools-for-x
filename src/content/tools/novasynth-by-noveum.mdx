## About
NovaSynth by Noveum helps developers test voice agent calls through phone or LiveKit endpoints. Configure caller personas and scenarios, run synthetic voice calls with noise or interruptions, then inspect recordings, transcripts and voice AI evaluation results. Rerun scenarios after changes for voice agent regression testing. Hosted freemium platform requiring an account and endpoint configuration.

## Features
- Phone and LiveKit voice agent call simulation
- Configurable caller personas and test scenarios
- Background noise and interruption testing
- Batch synthetic voice calls and repeatable regression checks
- Call recordings, transcripts and evaluation results
- Free plan with 2,500 monthly Noveum credits; voice testing uses 100 credits per call minute
- Pro plan from $69/month; extra evaluation checks may use credits
