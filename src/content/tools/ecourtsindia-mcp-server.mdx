## About

The eCourtsIndia MCP server (ecourtsindia.com/api/mcp) lets AI assistants search Indian court cases, read orders and analyse judgments from public court records.

## Features

- Works as a custom connector in Claude, Cursor and Gemini CLI
- Search by CNR number, party, advocate or judge
- Not legal advice
