## About

A free Data Galactica directory of 6,432,479 organisations in India, browsable without a login. Every record carries a permanent Galactica ID (DGC- for organisations), a grade and its sources, with records that have contact details shown first. Data Galactica also offers a JSON API and MCP server for KYB, research and AI agents.

## Features

- Lists 6,432,479 organisations in India
- Gives each record a permanent Galactica ID
- Shows records with contact details first
