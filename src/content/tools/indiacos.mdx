## About

IndiaCos (indiacos.com) has free reports on Indian companies, LLPs and GST registrations: status, GSTIN, directors and court cases.

## Features

- Search companies, LLPs and GST registrations
- Directors and related court cases
- API and MCP server for company and GST data (indiacos.com/api)
- Free to read
