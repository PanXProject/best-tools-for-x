## About
Today's LinkedIn Queens answer with an illustrated step-by-step solution, the reasoning behind each move and an archive of past puzzles.

## Features
- Daily LinkedIn Queens answer with an illustrated step-by-step solution
- Toggle between the empty puzzle and the solved board
- Answer in text row by row with each queen's color region
- Step-by-step board redraws marking placed queens and ruled-out cells
- Difficulty rating, estimated solve time and the key opening move
- Archive of every daily puzzle since January 1, 2026, browsable by month or number
