## About
Roblox Shirt Maker is an independent browser studio and [roblox clothing exporter](https://rbxshirtmaker.com/). Prepare original artwork with templates, imported PNGs, text, colors and layers, then inspect an R6 preview and keep editable work separately from a downloaded image.

## Features
- Start with a clothing template or import an existing PNG.
- Adjust text, colors and layers in the browser studio.
- Inspect the current draft using the displayed R6 avatar preview.
- Keep an editable project for later changes and download a PNG separately.
- Prepare appropriate classic shirt or pants layouts and graphic T-shirt images.
- Use the core manual editing, preview, saving and PNG download workflow free.
- Choose optional AI generation with an account and credits when useful.
