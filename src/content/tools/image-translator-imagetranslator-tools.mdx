## About
Image Translator reads text in uploaded images and renders a translation back into the visual while aiming to preserve its layout and style. It supports 132 languages for product graphics, comics, menus, documents and screenshots. New users receive 30 trial credits; each image and target-language task costs 10 credits, with paid subscriptions and credit packs for further use.

## Features
- Translate text within images into 132 languages
- Keep translated text within the original visual layout
- Preview and download each image translation separately
