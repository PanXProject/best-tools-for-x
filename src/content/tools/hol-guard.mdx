## About
HOL Guard runs on the developer's machine and checks what AI coding agents try to do (shell commands, secret reads, MCP servers and tools, package installs) before those actions run, so you can allow, block, or review them. Apache-2.0 open-source core with optional hosted Guard Cloud for teams. Checks reduce risk but are not a safety guarantee. Made by HOL.

## Features
- Pre-execution checks on agent shell commands
- Review of secret and credential access by coding agents
- Policy checks for MCP servers and tools
- Review of package installs requested by agents
- Local approval center with decision records
- Optional hosted Guard Cloud for shared team policy
- Install with pipx install hol-guard && hol-guard init
