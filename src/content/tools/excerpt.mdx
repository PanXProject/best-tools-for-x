## About

Excerpt is a selective multi-select clipper for ChatGPT, Claude, Gemini, and normal webpages. Click only the blocks you want—answers, code, quotes, tables—and store them in a private local IndexedDB library with full-text search. Export clean PDF or Markdown. Chrome/Edge extension. Free: 100 clips / 5 tags; Pro $29 one-time.

## Features

- Select only the blocks you want from ChatGPT, Claude, Gemini, and webpages
- Store clips in a private local IndexedDB library with full-text search
- Export clean PDF or Markdown
- Works as a Chrome and Edge extension
- Free plan includes 100 clips and 5 tags; Pro is $29 one-time
