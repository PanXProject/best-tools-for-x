## About
Hand On Web Image Compressor reduces the size of photos and graphics in your browser. Add up to 20 JPEG, PNG or WebP files, set the output size and quality, and download the results for your website or shop. The tool processes files locally and needs no account.

## Features
- Compress up to 20 images in a single batch
- Resize images before downloading the result
- Convert JPEG or PNG images to WebP
- Process images in the browser without uploading files
