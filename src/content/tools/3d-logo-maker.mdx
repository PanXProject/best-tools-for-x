## About
3D Logo Maker is a browser tool for adding depth to existing artwork. I am associated with the project and used AI writing assistance for this description. Review source permissions and the actual result before publishing it. Free 512-pixel PNG exports are watermarked; paid options differ.

## Features
- Import existing SVG and common image formats
- Adjust depth, bevel, lighting and materials
- Change camera angle and framing in a live preview
- Export an image with a transparent background
