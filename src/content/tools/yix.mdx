## About
YIX is a browser-based AI image and video studio for creators, designers and marketers. Generate images, edit photos, restore old photos, change backgrounds and create product visuals. Image and video generation require purchased credits.

## Features
- Generate images from text and image references
- Edit and restore photos in the browser
- Change backgrounds and remove unwanted objects
- Create AI videos and explore free prompt tools
