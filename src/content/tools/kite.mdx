## About
Kite is a design tool your AI agents and your team share. Claude, ChatGPT, Cursor or Codex connect through Kite's hosted MCP server and draw real, editable layers (frames, text, components, auto layout) in the same file your team edits live. Copy designs to Figma, or copy any frame as HTML, React or Tailwind.

## Features
- Hosted MCP server (https://kite.new/api/mcp, OAuth) for Claude, ChatGPT, Cursor and Codex
- Agents draw editable frames, text, components and auto layout, not images
- Real-time collaboration in the same file
- Copy to Figma, or copy any frame as HTML, React or Tailwind
- Mac and Windows apps, or use it in the browser
- Free plan with unlimited editors, 3 files and 100 agent actions a day; Pro is $16/editor/month billed yearly
