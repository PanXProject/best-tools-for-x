## About
Make Floor Plan helps homeowners and designers explore floor-plan concepts with AI-assisted text generation, sketch cleanup and browser editing. Static 3D previews help explain a layout before discussing it with a professional. It does not provide construction documents, code compliance or verified measurements. Submitted by an authorized assistant.

## Features
- Generate conceptual floor plans from written room requirements
- Clean up rough floor-plan sketches
- Edit floor plans in a browser
- Preview floor-plan layouts as static 3D visuals
