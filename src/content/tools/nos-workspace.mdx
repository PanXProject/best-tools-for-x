## About
NOS Workspace is for keeping documents alongside HTML reports and presentations. Paste HTML, preview it, and correct text on the page. Sign in to save your work and share a public link that readers can open without an account.

## Features
- Keep documents and HTML pages in the same workspace
- Edit visible text directly in the HTML preview
- Let readers reopen the shared link after you save a correction
- Try pasting and previewing before creating an account
