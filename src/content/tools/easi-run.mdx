## About
Run isolated Chrome sessions for external AI agents on your own Linux x86-64 server. Agents connect through MCP or REST, and a person can watch the same browser and temporarily take control for login, two-factor authentication or approval. Free AGPL-3.0-only software. Requires systemd and rootful Docker Engine 28+. You supply the host and separate agent.

## Features
- Live browser view and temporary human takeover
- Isolated Chrome sessions with encrypted saved profiles
- Browser control over MCP and REST
- File uploads and downloads
- Session recordings and action timeline
