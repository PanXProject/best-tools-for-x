## About

A free Data Galactica page on talent in Agra: the roles and skills listed by about 71,944 people in Agra, shown as counts with the top roles first. The most listed skills are Aptitude, English Language, Sales and General Knowledge. No individual is named, so it works as a hiring-market snapshot. Every Data Galactica record carries a permanent Galactica ID (DGC- for organisations, DGP- for people), a grade and its sources. Data Galactica also offers a JSON API and MCP server.
