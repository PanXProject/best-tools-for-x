## About
G Maps Extractor collects publicly available Google Maps business data for lead generation, market research, sales prospecting and local SEO. Search by keywords and export listings to CSV, Excel or JSON using the online cloud scraper or Chrome extension. Developers can use the Google Maps Scraper API for structured JSON responses. The Online free plan includes 1,000 records per month and up to two keywords per task.

## Features
- Extract public Google Maps business listings by keyword
- Export results to CSV, Excel or JSON
- Use the cloud scraper, Chrome extension or API
