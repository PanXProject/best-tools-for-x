## About
Image to STL converts JPG, PNG, JPEG and WEBP images into downloadable STL model drafts with a browser 3D preview. It also offers text and multiple-view workflows. Makers should review scale, orientation, manifoldness and supports in a slicer before printing. Generation uses credits; new users receive two trial credits, with paid plans for additional use.

## Features
- Convert reference images into STL model drafts
- Inspect geometry with a browser 3D preview
- Download STL files for review in your slicer
