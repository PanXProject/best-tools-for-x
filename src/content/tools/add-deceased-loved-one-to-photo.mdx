## About

Add Deceased Loved One to Photo is a browser-based tool for AI-assisted family-photo composites using a group image and a separate portrait. I am associated with the project; AI assistance helped draft this listing. Registration grants 10 credits once, enough for one generation; later generations are paid.

## Features

- Upload an existing group photograph and a separate reference portrait.
- Choose best-fit, left, right or centre placement before generation.
- Create an AI-assisted arrangement for an optional family keepsake.
- Add text captions to identify the result as an edited composite.
- Adjust the layout without spending additional generation credits.
- Download a result without spending additional generation credits.
- Use the web interface without installing a desktop application.

## Practical notes

Keep the unedited photographs separately, use images with permission, and review the result before sharing. A plausible-looking composition is not evidence that everyone was present at the original event or a guarantee of an accurate likeness. Caption, layout and download adjustments consume no additional generation credits; generating a new image is a separate credit-using action.
