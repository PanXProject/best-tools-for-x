## About
Novera is an Apache-2.0 AI workspace derived from Jan and maintained by TRON-ABS. Desktop and Android builds combine compatible local models and optional external model APIs for chat, documents and model management. The app is free; suitable hardware, separate model licenses and optional provider API charges apply. Capabilities depend on the chosen model and components.

## Features
- Chat with compatible models running locally
- Connect external model APIs using your own credentials
- Work with documents in a conversation
- Find and manage models through the model hub
- Connect supported MCP tools
- Use a multilingual interface

## Availability and source
Windows, Linux, macOS and Android releases are linked from the official site. macOS packages are not Apple-notarized. Source code, installation documentation and release history: https://github.com/TRON-ABS/Novera
