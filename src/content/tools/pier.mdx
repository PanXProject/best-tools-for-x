## About
Pier is a Windows 10/11 app that mounts WebDAV (Nextcloud, ownCloud, Synology, QNAP), SFTP and NFSv3 storage as a real drive with its own letter, so any program can open files from a NAS or cloud server as if they were local. Free for up to 5 drives; Pro is USD 19 per year.

## Features
- Real drive letter for WebDAV, SFTP and NFSv3 storage
- Block cache on the local disk keeps large files fast
- Interrupted transfers resume automatically
- Reconnects on its own after a connection drop
- Keeps working offline from the cache
- SFTP needs nothing on the server beyond SSH
