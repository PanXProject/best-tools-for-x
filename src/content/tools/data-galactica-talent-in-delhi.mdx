## About

A free Data Galactica page on talent in Delhi: the roles and skills listed by about 20,15,643 people in Delhi, shown as counts with the top roles first. No individual is named, so it works as a hiring-market snapshot. Every Data Galactica record carries a permanent Galactica ID (DGC- for organisations, DGP- for people), a grade and its sources. Data Galactica also offers a JSON API and MCP server.

## Features

- Counts the roles and skills people list in one city
- Shows the top roles first
- Names no individual person
