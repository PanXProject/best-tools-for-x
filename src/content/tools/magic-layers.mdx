## About

Magic Layers is an AI tool that splits any flat PNG or JPEG into editable layers. Upload one image and get back a base layer plus named, transparent PNGs for each element — text, subject, decorations, and background — complete with position data. Works with Photoshop, Figma, Canva, and game engines.

## Features

- AI-powered image layer separation from a single flat PNG or JPEG
- Each layer returned as a named, transparent PNG with position data
- Optional text prompt to steer the split (e.g. "separate all people")
- Choose 2–15 output layers per job; billed only for layers actually returned
- Far beyond background removal — text, decorations, and subjects all split apart
