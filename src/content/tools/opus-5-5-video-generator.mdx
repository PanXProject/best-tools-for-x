## About
Opus 5.5 Video Generator turns a text prompt into a 15, 30 or 60 second motion-graphics video. Claude Opus 5.5 storyboards the scenes, writes the animation code and checks its own preview frames, then every frame is rendered to a 1080p MP4 with sound in 16:9, 9:16 or 1:1. Built for launch videos, explainers, kinetic typography and animated charts; no install or API key.

## Features
- Makes 15, 30 or 60 second motion-graphics videos from a text prompt
- Claude Opus 5.5 storyboards the scenes and writes the animation code
- Renders a 1080p MP4 with sound in 16:9, 9:16 or 1:1
- Built for launch videos, explainers, kinetic typography and animated charts
