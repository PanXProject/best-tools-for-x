## About

verity-mod-guide is an unofficial guide to downloading, setting up, and troubleshooting Verity Mod. It covers setup, safety, and common issues.

## Features

- Step-by-step download and setup guidance for Java and Bedrock editions
- Safety checks so you can confirm authors, Project IDs, and file versions
- Troubleshooting for common issues, including missing dialogue and API errors
- Java versus Bedrock comparison to help you choose the right project
- No login, uploads, or API keys required to use the guide
