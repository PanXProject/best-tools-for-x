## About
SkillCopilotAI is a desktop AI interview copilot that captures live questions and produces structured answer outlines grounded in your resume and target role. It supports behavioral technical coding and system design interviews on Zoom Google Meet Microsoft Teams HackerRank CodeSignal and CoderPad. New users get a 60-minute free trial.

## Features
- Real-time interview answer guidance
- Resume and role personalization
- Coding and system design copilot
- Smart screenshot analysis
- Mobile mirror for interview follow-along
- Private desktop overlay for macOS and Windows
