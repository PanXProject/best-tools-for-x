## About

The Data Galactica API reference: JSON over HTTPS with open CORS at api.datagalactica.com/api/v1. Endpoints verify a company, verify a person in a role, match CRM rows to records, resolve any identifier to its Galactica ID, fetch many records in one call and run checks and diligence. Priced at Rs 0.16 a call. Every record carries a permanent Galactica ID (DGC- for organisations, DGP- for people), a grade and its sources. Data Galactica also offers a JSON API and MCP server.

## Features

- Verifies a company or a person in a role
- Resolves any identifier to its Galactica ID
- Matches CRM rows to records in one call
