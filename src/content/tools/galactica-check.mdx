## About

Galactica Check lets a person enter their e-mail, confirm a 6-digit code, and only then see the Data Galactica records linked to that address. They can claim a record, hide it, ask for its removal, or create their own Galactica ID. The same steps work over the API for agents. Part of Data Galactica.

## Features

- See records linked to your e-mail after a 6-digit code
- Claim, hide or request removal of a record
- Same steps over the API
