## About
UnoRouter is an open source LLM gateway with an OpenAI compatible API. One key reaches models from OpenAI, Anthropic, Google, DeepSeek, Qwen, Mistral and many more, with automatic failover between providers. Start on the free tier, then pay only for what you use.

## Features
- One OpenAI compatible endpoint for many model providers
- Automatic failover and smart routing across upstreams
- Works with Claude Code, Cline, SillyTavern, RisuAI and your own code
- Local first web chat that keeps history in your browser
