## About

UnoRouter is a model gateway for people weighing OpenRouter and other LLM routers who want the whole stack in the open. One OpenAI-compatible key reaches models from OpenAI, Anthropic, Google, Meta, DeepSeek, Qwen and Mistral, and requests fail over to a healthy provider automatically.

## Features

- **Open source**: frontend, gateway and provider sync are public, so routing and privacy can be checked
- **Local-first chat**: the built-in chat keeps history in your browser
- **Free models**: try it without paying, then pay as you go with no subscription
- **Same API you know**: works with the OpenAI SDK, Claude Code, Cline and OpenCode after a base URL change
