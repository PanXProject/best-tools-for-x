## About
MarkItDown is a free online converter that turns PDF, Word, PowerPoint, Excel, HTML, CSV, JSON, EPUB, URLs and images into clean, AI-ready Markdown. Choose private in-browser processing or fast server conversion, with AI OCR for scanned PDFs, table recovery and LaTeX math. No account required to start.

## Features
- Convert PDF, DOCX, PPTX, XLSX, HTML, CSV, JSON, EPUB and Jupyter notebooks to Markdown
- AI OCR for scanned PDFs and images with table recovery
- LaTeX math conversion
- Private in-browser processing or fast server conversion
- Markdown to PDF/Word export and Markdown viewer
- Available in six languages
