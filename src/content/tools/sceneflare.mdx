## About
SceneFlare is a web-based AI creation workspace for making and refining images and videos. Choose an available model, start with a prompt or supported visual references, and adjust generation settings where available. Image tools and a library help you continue working with your creations. Options vary by model.

## Features
- Generate images with available AI image models and editing tools.
- Create videos from text prompts, images, and supported reference inputs.
- Configure duration, aspect ratio, resolution, and audio when the selected model supports them.
- Use reference assets to guide the subject, scene, and visual direction.
- Revisit generated work in the library.
