## About
EUDR Tools is a free set of browser-based prep tools. Check whether a product code may fall within EUDR scope, inspect supplier plot files in Map Studio, and keep risk-assessment notes for your own review. It does not check land-use history or legality, certify compliance, or submit due diligence statements.

## Features
- Check HS/CN codes against the EUDR product list.
- Import GeoJSON and KML supplier plots for geometry checks.
- Preview repairs before exporting a corrected plot file.
- Create a structured Article 10/11 risk record for review.
