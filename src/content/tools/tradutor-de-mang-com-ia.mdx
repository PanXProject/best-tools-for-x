## About
O [tradutor de mangá com IA](https://www.mangatranslate.com/pt/ai-manga-translator/) da Ficory LLC reúne um leitor de mangás e uma plataforma empresarial de tradução. Usuários individuais traduzem páginas em lote e personalizam as traduções. Estúdios editam páginas em um editor online completo, semelhante ao Photoshop. A API integra a tradução aos fluxos de trabalho pessoais. A plataforma suporta todos os idiomas de tradução.

## Features
- Usuários traduzem páginas em lote.
- Leitores personalizam as traduções.
- Estúdios editam páginas online.
- Desenvolvedores integram a API aos fluxos de trabalho.
