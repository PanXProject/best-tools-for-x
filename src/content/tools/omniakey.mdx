## About
OmniaKey is a unified AI API gateway for developers, agents and teams. Instead of juggling separate accounts and keys for OpenAI, Anthropic and Google, get one prepaid, OpenAI-compatible API key for text, image, video and audio models, with pay-as-you-go billing and no subscription.

## Features
- One prepaid API key for GPT, Claude, Gemini and DeepSeek
- OpenAI-compatible endpoints for text, image, video and audio models
- Image and video models including gpt-image, Nano Banana, Seedance and Wan
- Pay-as-you-go usage-based billing with no subscription
- Works with Claude Code, Cursor, Cline and any OpenAI SDK
