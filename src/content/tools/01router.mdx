## About
01Router provides one API key for leading AI video, image, audio, and chat models. Teams can generate videos and images in the web studio or integrate video and image generation into products through APIs.

## Features
- Access multiple AI video and image models through one API
- Generate videos and images in a web studio
- Integrate video and image generation APIs into products
- Choose models and providers to match budget and quality
