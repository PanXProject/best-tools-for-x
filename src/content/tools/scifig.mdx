## About
SciFig helps researchers create scientific illustrations, charts and flowcharts for papers and presentations. Its workspaces support turning research ideas and data into visual figures.

## Features
- Create scientific illustrations for research
- Build data-driven charts and flowcharts
- Export editable SVG charts and flowcharts
