## About

IndiaRestros (indiarestros.com) lists restaurants, cafes, delivery kitchens, street stalls and dhabas across thousands of Indian cities, with dish search, menus and timings.

## Features

- Search by dish, city, area or cuisine
- Owners can claim and fix their page for free
- Free REST API and MCP server with no key needed for reads (indiarestros.com/for-agents)
- No commission and ranking never depends on money
