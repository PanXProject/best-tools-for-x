## About

The CareJobs Healthcare Jobs Data API publishes what the CareJobs.Now board reads every day as plain JSON and CSV: how many healthcare jobs are open by kind of job and employer (roles.json) and the hourly pay employers post by kind of job (pay.json, pay.csv), from 270 hospitals and health systems careers sites, updated daily. Built for researchers, journalists, workforce analysts and developers.

## Features

- Open healthcare jobs by kind of job and employer (roles.json)
- Posted hourly pay by kind of job (pay.json and pay.csv)
- Free, no API key, no sign-up
- CORS open, OpenAPI 3.1 spec
- Updated daily from about 270 hospital and health system careers sites
