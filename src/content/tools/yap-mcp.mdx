## About
Yap MCP is a free, open-source MCP server (MIT) that lets Claude, Cursor, VS Code, Windsurf and any MCP client transcribe local audio and video files of any length on your own computer. It uses NVIDIA Parakeet TDT v3, the same speech engine as the Yap dictation app. 25 European languages are detected automatically, with optional timestamps. Nothing is uploaded, and no API key or account is needed. Runs on macOS, Windows and Linux with Node.js 20 or later.

## Features
- Transcribes local audio and video files of any length
- Works with Claude, Cursor, VS Code, Windsurf and any MCP client
- Runs NVIDIA Parakeet TDT v3 on your computer, 25 European languages
- Nothing uploaded, no API key, no account, and it works offline after one model download
