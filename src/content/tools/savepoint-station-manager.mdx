## About
SavePoint is a self-hosted broadcast and streaming automation platform for running a fully managed 24/7 station, with segment, playlist and schedule management. Account and permissions management lets teams and streaming collectives run stations together, and RTMP server integration relays external live streams into scheduled segments. The base platform is free; simulcasting and VPS deployment are a one-time fee.

## Features
- Segment, playlist and weekly schedule management
- Account and permission management for running a station as a team
- RTMP live ingest relayed into scheduled segments
- Staging-to-production pipeline for pushing a station to a server
- Simulcasting to YouTube, Twitch, Kick, Discord and Mixcloud
- Runs on Linux, Windows and macOS
