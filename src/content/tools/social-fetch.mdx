## About
Social Fetch is an API that returns public social media data as JSON. Pull profiles, posts, comments, transcripts and search results with one API key, or connect AI agents through the hosted MCP server. Credits are pay as you go and never expire. New accounts get 100 free credits with no card.

## Features
- Profiles, posts, comments and transcripts as JSON
- Covers TikTok, Instagram, YouTube, X, Reddit and LinkedIn
- Hosted MCP server for AI agents
- Pay as you go credits that never expire
- 100 Free credits on signup, no card
