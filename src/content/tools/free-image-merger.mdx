## About
Free Image Merger is a browser image tool for combining pictures into one layout. Arrange images for collages, comparison sheets and social posts, then export a combined file. I build this tool for people who need a straightforward image-merging workflow.

## Features
- Combine multiple images into one composition
- Arrange image order and layout before export
- Prepare comparison sheets and shareable collages
