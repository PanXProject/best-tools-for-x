## About
BestLLMFor is a free browser calculator for indicative local LLM memory and quantization planning. Choose memory, context and use case to explore catalog suggestions. Estimates are not measured benchmarks, hosted inference or a guarantee of hardware fit. Validate choices on your actual runtime. The wider site has optional paid kits, affiliate links and analytics. Submitted by the publisher with AI assistance.

## Features
- Compare indicative memory and quantization estimates for catalog models.
- Switch between graphics memory and unified-memory planning.
- Explore 8K and 32K context assumptions before testing a model.
- Filter suggestions by intended use and read approximation notes.
