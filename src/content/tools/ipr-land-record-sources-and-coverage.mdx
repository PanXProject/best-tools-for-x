## About

A public list of every government source India Property Register is built from (land record portals, Local Government Directory codes, Survey of India village boundaries, India Post pincode areas and state registers), with a coverage page showing what is loaded for each state and record type. 19,81,51,667 plots are on the register. Free to read and cite.

## Features

- Every government source listed
- Coverage by state and record type
- 19,81,51,667 Plots on the register
