## About
BlooTrue is a no-code website widgets platform, an Elfsight alternative. Embed review feeds from 21 platforms (Google, Yelp, Trustpilot and more), before/after work galleries and new widget types on any site with one line of code. Free plan available.

## Features
- Visual editor with live preview
- One-line embed on any website builder
- Reviews from 21 platforms
- All-in-one blended review widget
- Before/after Work Showcase
- 100+ Styles
- Auto-translation into 68+ languages
- Unlimited views on every plan
- Free plan
