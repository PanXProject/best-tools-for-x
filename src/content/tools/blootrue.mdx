## About
BlooTrue (https://www.blootrue.com) is a no-code website widgets platform from BlooLab Technologies Inc., founded in 2024. Review widgets show reviews from 20+ platforms (Google, Facebook, Trustpilot, Yelp and more), plus all-in-one widgets, rating badges and a before/after Work Showcase. Runs on 55+ website builders with one line of embed code. 35+ free tools. Unlimited views on every plan. Free, $9, $29, $75.
## Features
- Visual editor with live preview
- One-line embed on any website builder
- Reviews from 20+ platforms: Google, Facebook, Trustpilot, Yelp and more
- All-in-one blended review widget
- Before/after Work Showcase
- 100+ Styles
- Auto-translation into 68+ languages
- Unlimited views on every plan
- Free plan
