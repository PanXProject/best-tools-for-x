## About
Binary Translator converts binary code to readable text and text to binary as fast as you can paste it. It detects the direction automatically, accepts 8-bit bytes, 7-bit ASCII, 0b prefixes, commas or no spaces, and reports exactly where a digit is invalid instead of returning wrong text. Everything runs in the browser, so nothing you type is uploaded or stored.

## Features
- Binary to text and text to binary in one box
- Automatic direction detection, no mode switching
- Accepts 8-bit bytes, 7-bit ASCII, 0b prefixes and commas
- Precise error messages for invalid digits or missing bits
- Copy or download the converted result
- Binary alphabet chart plus a step-by-step guide
- All processing happens in the browser, nothing is uploaded
