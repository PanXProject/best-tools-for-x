## About
ScrapeAtlas is a unified social media data API for public profiles, posts, videos, and conversations across ~40 platforms. Use the REST API with an x-api-key, or the hosted MCP server so AI agents can pull social data directly. Freemium: 100 free credits, no card. Company: OD. Media & Technology LLC.

## Features
- Unified API for public profiles, posts, videos and conversations
- Coverage across roughly 40 social platforms
- REST API authenticated with an x-api-key
- Hosted MCP server (Streamable HTTP, Bearer auth) for AI agents
- 100 Free credits with no card required
