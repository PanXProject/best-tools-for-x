## About
I use DreamMMer when I have a rough product shot and only a vague idea of the look I want. You describe the edit in plain words, the agent writes the real prompt and picks which image or video model to run, then you keep nudging it in chat. New accounts get 50 free credits, enough to see if it fits before paying.

## Features
- Template gallery for banners and product stills, so you don't start from a blank box
- One-click cleanup tools like upscale and background removal
- Reference-image mode that keeps the output close to the real product
- Image and video models in one place, picked for you by the agent
