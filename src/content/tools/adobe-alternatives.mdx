## About

Adobe Alternatives is an independent directory of selected ArtCraft creative projects. It organizes image editing, vector illustration, RAW photography, PDF and motion graphics tools, with supported platforms, development stages and official links. A comparison table helps readers shortlist tools before testing their own files. A separate guide covers SolidCraft CAD. Browsing is free, with no account required. The directory is not affiliated with Adobe or ArtCraft.

## Features

- Compare creative tools by workflow, supported platform and development stage
- Follow official project links to verify downloads and current documentation
- Browse image, vector, RAW photography, PDF and motion graphics categories without an account
