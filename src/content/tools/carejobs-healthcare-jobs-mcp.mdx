## About

Free remote MCP server (Streamable HTTP) at https://carejobs.now/api/mcp for AI agents and developers. It searches 170,000+ open US healthcare jobs read daily from 270 hospitals' and health systems' career sites, and shows the pay each employer posts.

## Features

- Search open US healthcare jobs by keyword, state and kind of job
- Posted hourly pay by kind of job
- Job details, employers, states and kinds of job
- Six read-only tools, no API key, no sign-up

Official MCP Registry name: now.carejobs/healthcare-jobs. Source (MIT): https://github.com/yumaheymans/carejobs-mcp
