## About
SoldFetch provides eBay listing data for developers, pricing tools, and resellers. Search sold and active listings, browse categories, and look up individual items through REST or MCP. An installable eBay skill supports agent workflows. Responses preserve displayed-price context and explicit uncertainty around accepted offers and sale dates. Start with 100 free units; paid plans start at $9/month. Not affiliated with eBay.

## Features
- Sold and active eBay listing search.
- Category browsing and individual item lookup.
- Up to 200 search results per request.
- Ebay.com, ebay.co.uk, and ebay.de support.
- REST, MCP, and an installable agent skill.
- Shared authentication and plan allowance across REST and MCP.
- Explicit price and date quality semantics.
- Documented JSON responses and public developer examples.
