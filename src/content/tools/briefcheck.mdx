## About
Briefcheck helps freelancers and small studios turn vague client requests into clearer project briefs before estimating or starting work. Check an existing brief for missing commercial details, or create a private questionnaire link for a client. Core tools are free without an account; an optional human rewrite is available after fit is confirmed.

## Features
- Checks goals, deliverables, audience, timing, budget and scope boundaries
- Creates private client brief request links with structured questions
- Offers project-specific brief templates for websites, branding, apps and campaigns
- Keeps brief text private and does not require an account
- Provides an optional fixed-price human rewrite for quote-ready scope
