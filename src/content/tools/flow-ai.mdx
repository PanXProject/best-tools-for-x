## About
Flow AI (https://flowai.studio/) is a free, browser-based AI video generator for creators and teams. Turn prompts, images, and references into original videos using text-to-video, image-to-video, and first/last-frame generation. Describe a shot, generate, and iterate in a zero-friction video workspace without signing up.

## Features
- Generate videos from text prompts
- Create videos from images
- Use first and last frame generation
- Create in the browser without signing up
