## About
Cartoon Video AI is a browser-based animation tool for creators, educators, and small teams. Start with a text prompt or an image to plan a short cartoon scene. Review the draft before using credits for video generation.

## Features
- Start with a written prompt or an existing image
- Plan a short animated scene before generating video
- Work in a browser without installing desktop software
