## About
FoxPhone is a cloud phone platform with isolated Android devices in the cloud. Each phone has its own device fingerprint and IP, so AI agents can install apps and run tasks at scale from the browser.

## Features
- Isolated Android cloud phones with unique device fingerprints
- Dedicated IP per device so environments stay separate
- AI agents can batch-install apps and run tasks
- Control one phone or hundreds from the browser
- Free trial, then usage-based freemium pricing
