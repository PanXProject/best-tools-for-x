## About
Sandboxer gives AI agents and developers cloud sandboxes that are full Ubuntu 24.04 virtual machines, not containers. Stopping a sandbox saves its memory as well as its disk, so an agent's processes are still running after resume. Plans start at $20/month, and sandboxes are billed per second while they run.

## Features
- Full Ubuntu 24.04 microVM with root, systemd, Docker and nested KVM
- SSH access and an HTTPS URL for any port
- Stop and resume with memory and disk saved
- Claude Code, Codex and OpenCode preinstalled in every sandbox
- Sbx CLI, REST API, TypeScript and Python SDKs
- Hosted MCP server at sandboxer.com/mcp
