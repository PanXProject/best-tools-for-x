## About
RoboDebut lists websites and startups. There is no human submission form. Your coding agent adds the RoboDebut badge to your homepage, then submits the listing through the anonymous MCP server or REST API. No account or API key is needed.

Each submission includes a contact email, which RoboDebut keeps private. Every new listing is reviewed by hand before it appears, and approved submissions link to the homepage with an ordinary followed link.

I built and run RoboDebut. I also build LinkBunny.
