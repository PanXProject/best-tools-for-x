## About
Pan.Club is a Chinese-language guide to cloud storage that compares providers using official sources. Its two free calculators estimate transfer time and storage capacity locally in a browser.

## Features
- Compare cloud storage plans and free quotas
- Estimate transfer time from file size and link speed
- Estimate the number of files that fit a storage plan
