## About

Youth4work Prep has mock tests and practice questions, free to start, for Indian government, banking, railway, defence, entrance and placement exams, with a discussion forum for each exam. Part of Youth4work, an Indian skills-assessment and careers network running since 2012.

## Features

- Mock tests for government, banking, railway and defence exams
- Entrance and placement exam practice
- A discussion forum for each exam
