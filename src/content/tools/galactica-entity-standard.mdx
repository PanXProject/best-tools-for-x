## About

The Galactica Entity Standard v1 is the one schema every organisation and person on Data Galactica follows, served by the pages, the API and the MCP server. Ids are DGC- (organisations) or DGP- (people) plus 12 Crockford base32 characters; source ids such as CIN, LLPIN, LEI, SEC CIK and Wikidata Q-ids resolve to them. Industry uses ISIC Rev.4, places use ISO 3166.

## Features

- DGC-/DGP- ids
- ISIC Rev.4 industry
- Served by API and MCP
