## About
Free browser-local PNG & web image toolkit (compress, resize, crop, trim, convert PNG/WebP/JPG/AVIF/PSD/SVG, remove backgrounds, optimize APNG) running on-device via WebAssembly & Web Workers with zero image uploads. Free for all local tools (up to 50 files per batch, folder uploads, ZIP downloads, no sign-up or watermark). Optional Pro Ad-Free membership ($6/month or $36/year). About: https://alphapng.org/about | Pricing: https://alphapng.org/pricing

## Features
- Compress PNG & SVG files locally by quality or target size
- Resize, crop, trim, and convert PNG, WebP, JPG, AVIF, PSD, and SVG
- Remove backgrounds and optimize animated PNGs (APNG) on-device
- Runs locally via WebAssembly & Web Workers with zero image uploads
- Free for all local tools: up to 50 files/batch, folder uploads, ZIP downloads, no sign-up or watermark
