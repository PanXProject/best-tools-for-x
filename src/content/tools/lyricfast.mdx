## About
LyricFast helps musicians make lyric videos in a browser. Upload a song, generate word-level lyric timing, adjust lines, and preview the whole video before exporting. Full-song previews are free, and finished exports use credits.

## Features
- Generate word-level lyric timing from a song
- Edit lyric timing and preview the full track
- Export a finished lyric video using credits
