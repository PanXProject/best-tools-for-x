## About

ValRequest is an AI-powered Valentine's message generator. Choose your recipient, pick a style (heartfelt, humorous, Shakespearean, or cute), add personal keywords, and get three personalized greeting options in seconds. Free to start with daily check-in credits.

## Features

- AI-generated personalized Valentine's messages
- Multiple styles: Heartfelt, Humorous, Shakespeare, Cute
- Supports partner, crush, and friend recipients
- Keyword input for a personal touch
- Generates 3 message options per request
- Save and share messages as an image
- Daily free credits with sign-up
