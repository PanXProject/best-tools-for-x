## About

Data Galactica (datagalactica.com) gives a permanent Galactica ID to 95.6M people and 28.6M organisations in 252 countries, each with a card saying where it came from and how sure the match is.

## Features

- Verify and resolve any id (CIN, LEI, Wikidata and more)
- Search and match CRM rows
- JSON API and MCP server: Rs 50 free, then Rs 0.16 a call (datagalactica.com/api)
