## About
ROB RUN Wiki is an independent player guide to ROB RUN, the free-to-play crime sandbox on Steam. It covers server status and regions, how to change server, every official error code, the weekly Federal Raid wipe (with a per-server wipe timer), a live Steam player chart, and guides to money, heists, cargo, bases, police and vehicles. Facts come from official sources with last-checked dates. Free, no account. Not affiliated with Kefir.

## Features
- Per-server wipe timer based on the official 7-day cycle
- Live Steam player count chart
- Every official error code with its fix
- Server status, regions and change-server guides
- Money, heist, base and police guides with official sources
