## About
Mails.ai gives an AI agent its own email address through one API call, so it can send, receive and reply. Replies, deliveries and bounces reach your code as signed webhooks or a live stream, and every incoming message is scored for prompt injection before your agent reads it.

## Features
- Its own email address for each AI agent, from one API call
- Send, receive and reply over REST, with TypeScript and Python SDKs
- An MCP server and a CLI, so a coding agent can use it directly
- Replies, deliveries and bounces as signed webhooks or a live stream
- Every incoming message scored for prompt injection, with high-risk mail flagged
- A test key runs the whole API without sending real mail
- A free plan with 3,000 emails a month and no card; Pro is $20 a month and Scale $99
