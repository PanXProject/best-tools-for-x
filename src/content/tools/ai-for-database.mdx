## About

AI for Database provides a browser product and a scoped REST API for working with operational databases. Teams can ask natural-language questions against connected data, inspect query results, create dashboards, and configure scheduled workflows with authenticated webhook actions. Public API access uses organization-scoped keys and documented safety boundaries.

## Features

- Natural-language database questions
- Dashboard creation
- Scheduled database workflows
- Authenticated webhook actions
- Scoped REST API keys
- OpenAPI documentation
