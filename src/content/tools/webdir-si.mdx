## About
WebDir.SI is a human-edited web directory listing 15,600+ reviewed websites across 97 categories. Every site is checked by an editor before going live, and the built-in Ask SI assistant helps visitors find the right website for any topic in seconds. Site owners can suggest their site for a free review.

## Features
- 15,600+ Hand-reviewed websites in 97 categories
- Ask SI assistant that recommends the right site from your question
- SI quality scores on every listing
- Free submission with human review
- Permanent, organized listings that keep sending visitors
