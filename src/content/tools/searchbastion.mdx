## About
SearchBastion is a free SEO audit and website analytics dashboard. Connect Google Search Console, run technical SEO audits, track rankings and uptime, and get a prioritized list of fixes in one place.

## Features
- Free technical SEO audit
- Search Console insights
- Keyword rank tracking
- Uptime monitoring
