## About
SendVeil is a web service for sending large original files to clients and other recipients through a private download link. If the connection drops, the sender picks the same file again and the transfer resumes where it stopped. Recipients download without creating an account, and files are not compressed or converted. SendVeil does not offer end-to-end encryption. It is run by Michael König-Weichhardt in Graz, Austria.

## Features
- Private download link with an expiry date set by the sender
- Optional password for the link
- Transfers resume after a dropped connection
- Original files downloaded with no compression or conversion
- Free plan: 5 GB per transfer and 7 days of storage
- Interface available in 20 languages
