## About

The Youth4work MCP server lets an AI assistant use Youth4work through the Model Context Protocol (Streamable HTTP, OAuth 2.1). Job seekers can update profiles, find and apply to jobs and see skill scores; employers can post jobs and run assessments. A public read-only endpoint searches talent, jobs, mock tests and colleges without sign-in.

## Features

- Connects AI assistants to Youth4work over MCP
- Uses OAuth 2.1 sign-in with a Youth4work or Google account
- Has a public read-only endpoint for jobs, tests and colleges
