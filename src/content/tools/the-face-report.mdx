## About
25 free face measurement tools: face shape, symmetry, golden ratio, jawline, canthal tilt, eye shape and facial ratios. Most run in the browser on 478 facial landmarks, with no account and no upload, and show the formula behind each score. An optional full report costs $17.49 once.

## Features
- Face shape detector with hairstyle and glasses guidance for each shape
- Symmetry test: left vs right across eyes, nose, mouth and jaw
- Golden ratio face test
- Jawline score with a measured gonial angle
- Canthal tilt, eye shape and facial ratio tests (FWHR, midface ratio and more)
- Most tools run in the browser: no account, no upload
- Optional full report: $17.49 once, no subscription, 7-day refund
