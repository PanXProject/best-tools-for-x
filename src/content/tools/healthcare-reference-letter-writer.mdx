## About
Healthcare Reference Letter Writer is a free AI tool for nurse managers, preceptors, instructors and coworkers asked to recommend a healthcare worker, or for job seekers drafting a letter for their reference to edit. It writes the letter from the facts given only. No sign-up.

## Features
- For a job, nursing school, NP program, residency or travel agency
- Built from the examples you write
- Reminder that the writer approves it before sending
- Free, no sign-up, nothing stored
