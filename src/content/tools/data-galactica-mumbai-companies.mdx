## About

A free Data Galactica directory of 252,933 organisations in Mumbai, browsable without a login. Every record carries a permanent Galactica ID (DGC- for organisations), a grade and its sources, with records that have contact details shown first. Data Galactica also offers a JSON API and MCP server for KYB, research and AI agents.
